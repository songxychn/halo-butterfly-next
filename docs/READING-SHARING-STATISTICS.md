# 阅读、分享与统计

当前范围见 [DEC-10](parity/DEC-10-THEME-SCOPE.md)。保留文章字数、阅读时间、复制提示及繁简转换；不再在访客浏览器遍历全站文章计算总字数。

`share.use` 只支持关闭或 `native`。原生模式总有链接输入框和复制按钮；剪贴板不可用时选中文本供手动复制；浏览器支持系统分享才显示系统分享按钮。无第三方分享 SDK。

后台「Halo 阅读量」中的开关控制单篇阅读量与全站文章累计阅读量，直接读取 Halo 数据，不代表独立访客数或全站所有页面 PV。不再提供 UV、不蒜子或 Umami 私有统计。为兼容配置存储，两个开关仍叫 `busuanzi.page_pv/site_pv`。

旧 Share.js/AddToAny 配置由离线迁移转换为原生分享并提示；旧不蒜子统计开关关闭，核对口径后可再开启。
