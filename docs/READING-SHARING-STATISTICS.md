# 阅读、分享和统计

固定参考：Butterfly 5.7.0（`f223b1888b42b2b336068e6c959ed90a3cd7c8f3`）。本批对应正文复制、繁简转换、字数/时长、网站信息 PV/UV 和文章分享。

## 正文复制

`copy.enable` 默认开启；关闭时阻止文章和自定义页面正文的普通选择复制。这是阅读交互开关，不是内容访问控制。代码块、代码复制工具栏、表单和正文以外区域沿用各自行为。

`copy.copyright.enable` 默认关闭。开启后，选区字符数严格超过 `limit_count`（默认 150）才追加文章作者、规范链接、站点名和当前版权许可。0 表示非空正文选区即追加。选区不跨出正文；短选区保留浏览器原始复制。剪贴板写入被拒绝时保留正常复制，不清空剪贴板。

## 繁简转换

新增 `translate.defaultEncoding`：1 为繁体原文、2 为简体原文，默认 2。`translateDelay` 默认 0，单位毫秒，限制为 0–60000，控制保存偏好的恢复延迟；延迟期间点击会先完成恢复，再执行切换。`msgToTraditionalChinese` / `msgToSimplifiedChinese` 默认为“繁”/“簡”；`translate.default` 保留初始按钮文案。

转换跳过代码、脚本、样式、表单输入、SVG、模板和 `translate="no"` 内容。浏览器存储不可用时当前页仍可切换。原始编码应与站点作者内容一致；这不是自动语言识别或专业翻译。

## 字数与阅读时长

保留 `wordcount.enable` 默认关闭、`post_wordcount` / `min2read` 默认开启。中文汉字按字统计，其他语言按连续字母/数字词统计，词内撇号不拆词。忽略 HTML 标签、注释、脚本、样式、模板、SVG、空白和标点；正文代码文本计入。中文采用 350 字/分钟，其他语言采用 160 词/分钟，混合时间相加后向上取整；空正文为 0。速度来自上游文章元信息的 `min2read(...,{cn:350,en:160})`，词法是明确的 Halo 适配，不声称与任意版本 hexo-wordcount 完全一致。

文章元信息在服务端计算，无 JavaScript 也显示；主题新增的过期提醒、工具栏等不计入正文。服务器使用 Halo 随带的 HtmlEscape 解码实体，浏览器全站汇总使用 DOMParser 解码。

`total_wordcount` 为网站信息卡片新增选项，默认关闭。开启后，卡片进入视区才通过匿名公开 API 遍历公开已发布文章，详情最多两个并发。读取 `PostVo.content.content`，不读控制台、草稿、快照或私人文章接口。当前标签页缓存 5 分钟，文章数或最新更新时间变化会失效。关闭卡片/全站字数时没有汇总请求。空站输出 0，任何详情失败、重复分页或发布数量变化均显示“暂不可用”，不展示部分总数；总请求窗口最多 60 秒。

大型站点需逐篇读取正文，建议保持该选项关闭；浏览器首次汇总的成本和缓存时效是本实现的限制，不能视为性能合同已通过。

## PV / UV

`busuanzi.provider` 默认 `halo`。`page_pv`、`site_pv`、`site_uv` 默认关闭。

Halo 来源直接读取文章 `post.stats.visit` 和 `siteStatsFinder.getStats().visit`；后者是文章累计阅读量，界面明确这样标注。Halo 原生没有 UV，因此这一来源不显示独立访客数，不把 PV 冒充 UV。数据契约见 [Halo 站点统计文档](https://docs.halo.run/developer-guide/theme/finder-apis/site-stats/)。

显式选择 `busuanzi` 时使用 [不蒜子 2.3 官方接入](https://ibruce.info/2015/04/04/busuanzi/)：按需要渲染 `site_pv` / `site_uv` / `page_pv`，只在存在实际显示项时异步引入官方脚本。它向第三方发送访问请求，口径与历史 Halo 计数不同。服务不可用时保留“暂不可用”，页面不会等待统计。主题不自建访客身份、不迁移或虚增历史值。

## 分享

`share.use` 默认空（关闭）；支持 `native`、`sharejs`、`addtoany`。只在文章详情出现，使用文章标题、规范链接和封面；启用 SEO 与否均可获取同一规范链接。任意方式都提供复制链接和只读链接框，剪贴板被拒绝时聚焦、选中链接以便手动复制；支持 Web Share 的浏览器额外显示系统分享按钮，用户取消不报错。

Share.js 使用固定上游 `butterfly-extsrc@1.1.6` 的分享脚本、CSS、字体和本地微信二维码，随包分发；仅选择该方式时加载。`sharejs.sites` 默认 `facebook,x,wechat,weibo,qq`；支持另加 twitter、qzone、linkedin，未知项过滤、去重保序，空列表不显示平台入口。微信二维码支持键盘聚焦、点击打开及 Escape 收起。

AddToAny 的 `addtoany.item` 沿用上游默认列表，以英文逗号分隔服务标识；空列表不加载在线脚本。启用后加载其官方在线服务，超时/失败保留手动链接和平台 URL 回退。真实账号提交分享不属于主题本地验证。

## 升级、回退与验收

旧配置缺新增字段时沿用上述默认值，不自动开启分享、第三方统计或全站汇总。原 `busuanzi.page_pv` 开关继续使用 Halo 原生阅读量，除非作者主动选择不蒜子。迁移工具按已有分组字段规则复制新设置并记录不支持字段。回退旧包后新增字段不再使用，文章数据保持原有格式。

局部开发和验收仅更新为 `implemented-unverified`；完整固定双站对照、真实分享账号/第三方统计服务、跨浏览器/真机及完整 1.0 性能门禁另行记录。
