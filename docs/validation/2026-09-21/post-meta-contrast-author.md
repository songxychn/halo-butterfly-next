# 文章顶图元信息对比度修复（#319）

范围：文章顶图中的日期、分类、标签、字数/阅读时长/访问数及评论数。仅在 `.post .header .above .post-meta` 内增加局部可读底板，保留 `mask.header` 的整张顶图遮罩开关；关闭第一屏后，正文卡片元信息继续使用原样式。分类/标签链接常显下划线，悬停加粗下划线，键盘焦点显示外侧白色框。

底板为 65% 黑，文字为不透明白。以关闭顶图遮罩、纯白封面作为最亮背景，合成后背景通道为 `255 × (1 − 0.65) = 89.25`，按 sRGB 相对亮度计算文字对比度为约 **6.98:1**。开启亮/暗模式遮罩只会进一步降低背景亮度。元信息伪元素的分隔符继承局部白色 token；评论数保留 #318 的独立底色及内侧焦点框。
