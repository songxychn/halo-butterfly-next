## 环境与覆盖

实验在自有 `http://127.0.0.1:18845`、官方 Halo 2.26.1 运行。269 个安装文件逐字节匹配 ZIP；官方 CommentWidget 3.3.2、KaTeX 3.0.0、Moments 1.18.0、Links 2.3.0 的 JAR 指纹锁定，均实际 STARTED。其他原有官方插件保留，包括 SearchWidget 1.8.0。现有诊断用 layout-probe 在测量前停用，未参与这三批检查；准备与结束恢复另有记录。

每个文章检查点核对唯一公式／MathML／复制按钮、精确 TeX 注解及复制处理器输出、唯一代码工具栏、响应式图片结构与显式 eager、灯箱键盘打开／关闭及焦点复归。文章、瞬间分别检查唯一官方评论组件的 group／kind／name 及表单；友链检查本地合成链接与无评论组件。英文文章、日文瞬间、韩文友链分别核对语言，日／韩还核对实际浏览器文案。每个检查点均要求无未完成请求、HTTP／网络失败或未捕获页面错误。

公式由固定官方插件 JAR 内 KaTeX 0.16.25 按官方默认编辑器参数生成 MathML，再经内容 API 保存。这是保存格式控制，不是公式编辑器 UI 验收。复制使用只读结果捕获接口，不证明操作系统剪贴板。所有内容均为本批随机名称、明确归属的合成夹具。

主题既有 `supportsPartialNavigation()` 对未声明支持局部替换的可执行脚本保留完整文档生命周期。本批 90 次导航记录均明确观测到同源官方 SearchWidget 1.8.0 的 `search-widget.iife.js?version=1.8.0` 无主题脚本标记，足以要求原生生命周期；这些记录没有同时采集到 CommentWidget 的 `script[src]`。因此不能把原生回退解释成语言切换缺陷，也不能要求为了让测试通过去改造插件。新批检查新文档中的组件唯一性与正确身份，不使用跨文档已经不存在的对象来宣称 PJAX 销毁通过。

首批清理还发现官方 Moments 控制器异步新增 `approvedTime`。严格规格摘要检查因此保留该合成瞬间和锁；独立读取确认仅移除此字段即可重现登记摘要，且名称、标签、创建时间完全匹配后，才精确删除，另存 `cleanup-supplement.json`，四个对象均确认 404。原失败报告未改写。后两批在固定 20 秒观测截止内等待这一个官方字段及版本收敛，再冻结完整规格；删除仍比较完整规格，不跳过校验。HTTP 客户端自身超时仍为 60 秒，但晚于 20 秒的收敛响应不算通过。
