## WebKit 深色失败的边界

第三轮进入 Moment 前后，request 179 请求 `/lab/cover-misty-forest.webp`，在 `12:58:50.105Z` 开始、`12:58:50.110Z` 以 `cancelled` 结束，没有响应状态；紧接着 request 180 的 Moment 主文档于 `12:58:50.111Z` 开始并完成 HTTP 200。严格检查在第三轮 Moment 检查点捕获此前取消，因此该检查点和后续计划未计通过。

时序提示可能涉及整页离开时的图片取消，但现有记录不含请求所属文档身份与发起栈，不能据 `stage` 字段断言它来自新 Moment 页：工具在点击前已更新该字段。不能认定是 Halo #338、灯箱回归，或直接豁免为正常取消。原始失败保留，未放宽网络门禁或通过重跑改判。下一步应在独立诊断中记录文档身份、发起源和导航时序，再判断是否需要修正请求归属或产品行为。
