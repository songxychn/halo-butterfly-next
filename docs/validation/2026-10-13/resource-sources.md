## 复核方法

先执行 `bun run verify`，按 [比较实验室](../../COMPARISON-LAB.md) 准备隔离 Halo，再安装新 ZIP。把完整 `templates/assets/` 复制到本地静态镜像，选择 `CDN.internal_provider: custom`、完整 assets 根地址和 `third_party_provider: inherit`；资源请求必须保留 JS/CSS/字体/插件目录。

依次核对首页资源和字体、分页往返、文章 Share.js、显式不蒜子脚本覆盖、动态效果；再将根地址改成不存在的路径以及带查询参数的无效地址，核对本地回退。单元回归另外验证解析优先级、错误与缺失 API 的单次回退、请求复用、超时不重试和 PJAX 地址约束。复核完成后恢复测试前配置并读回比较。

本轮准备与执行脚本、原始日志保存在 git-ignored `.runtime/`；共享记录保留结果、失败原因和日志哈希，不包含管理员凭证或配置正文。

## 失败与修正保留

1. 新设置导致原性能默认快照过期：从 settings.yaml 重新冻结，完整门禁重跑。
2. 初版默认插图模板替换把 JS replacement 的 dollar token 当特殊语法，Halo 解析失败：改用回调替换，再安装渲染。
3. 镜像最初放错附件目录：更正到 Halo 实际 attachments 目录；未改变产品断言。
4. 最初把 Share.js 字体族写成 socialshare：核对源码后更正为 iconfont。
5. 每种配置各自登录触发本地登录限流；复用一次认证后的客户端，未通过重试绕过产品失败。
6. 新增默认头像回退检查失败：已有内联错误处理先换成 GIF。为默认头像增加本地插图优先回退，保留自定义头像原兜底，并重新执行全部门禁、安装比对和 8 组浏览器检查。
