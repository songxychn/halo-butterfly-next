# 页面加载与字体性能：当前候选验收

本轮开始于 2026-10-15，移动性能采样跨至 Asia/Shanghai 的 10 月 16 日；每份原始 Lighthouse 报告的 UTC 时间保存在[机器记录](loading-performance-next.json)。结论：**默认配置的首页和长文移动性能中位数达到本轮预算；完整 1.0 性能合同及既有加载停滞问题仍未关闭。**

## 当前改动

主题随包的 Font Awesome 保留完整原始 CSS、全部字体、FA4/5 别名与许可证，另提供三份改名为 Butterfly Icons 的小字体。它们覆盖主题源码和设置默认值中静态使用的 62 个码点；任意自定义图标继续使用完整原字体。三份 WOFF2 总计由 302,376 字节降为常用子集的 **9,088 字节**，不删减可用图标。

每个新 CSS family 内按字符范围选择子集或完整字体；子集请求或解码失败时，依次回退原 WOFF2、原 TTF。普通构建仅校验九项上游输入及生成产物哈希并复制，不新增 Python 字体工具依赖。需要更新子集时，维护者使用固定 FontTools 4.60.1 / Brotli 1.1.0 再生。原始轮廓、逐字形宽度与关键全局字体指标保持，命名和许可见[字体来源说明](../../../src/fonts/fontawesome-subsets/NOTICE.md)。

主题 CSS 通过仅由随包 Font Awesome CSS 定义的变量选择新 family；管理员选择原版 CDN CSS 时自然使用原 Font Awesome。保留官方 `--fa-style-family` 自定义入口及主题已有 FA7 优先顺序。没有改变 Halo 最低版本、官方插件、评论/KaTeX 资源行为，也没有引入浏览器特判或字体加载 JavaScript。

| 页面 | 基线 LCP 中位数 | 候选 LCP 中位数 | 基线 → 候选 TBT 中位数 | 基线 → 候选 CLS 中位数 |
| --- | ---: | ---: | ---: | ---: |
| 首页 | 4057.008ms | **2030.760ms** | 0 → 0ms | 0 → 0 |
| 长文 | 2784.063ms | **2033.090ms** | 72.5 → 95.5ms | 0.000847 → 0.000847 |

两页候选中位数满足 LCP ≤2500ms、TBT ≤200ms、CLS ≤0.10。长文 TBT 增加 23ms，未同时超过相对退化的 10% 与 100ms 门槛。请求数分别仍为 19 / 27；总传输量中位数分别从 1,272,805 / 760,915 字节降至 984,026 / 494,966 字节。真实 Halo 的候选首页请求三份子集字体，长文请求两份，均未请求完整 Font Awesome 字体。

候选首页第一个样本仍为 **3958.212ms**，其余为 1658.626 / 2030.760 / 2030.995 / 2029.963ms；没有将慢样本移除。中位数达标不代表每次访问都小于 2.5 秒，也不代表真实用户性能。旧的约 4.65 秒诊断来自另一候选，本轮以重新测得的基线作比较。

## 兼容性与验证边界

三引擎无头隔离图标夹具共 **42/42** 项通过。每种变体都与同引擎、同图标的原版 CSS 结果比较解码后的 RGBA 像素，而非依赖字体名称或 `document.fonts.check`：

- 常用图标和无 JavaScript 仅请求三份子集，图标像素与原版相同。
- 任意子集外图标、FA4 别名、显式 FA5 family、原版 CDN CSS 保持相同图标。
- 子集 HTTP 503、子集损坏、全部 WOFF2 失败但原 TTF 正常时，均能回退并保持相同图标。

这些是受控字体夹具；CSS 和字体响应由本地文件路由提供，不冒充完整网站三引擎验收。真实 Halo 安装后的十次候选性能样本另行验证了默认页面资源路径。独立审查核对了完整 cmap 的无遗漏分配、62 个字形的轮廓/宽度、全局字体指标、OFL 改名以及可重复生成；审查发现的 TTF 回退遗漏已修复。

精确候选 `6552308` 的完整 `bun run verify` 通过：756 项测试、类型/矩阵检查、构建和 269 文件包检查均通过；再次构建的 ZIP 哈希仍为上面的 `93b6a78…`。没有用旧候选的门禁代替本次结果。

[页面请求停滞诊断](loading-reliability.md)是另一个有明确候选归属的批次，40/40 未复现不等于已修复。首页、文章、单页、归档、标签等旧失败继续保留。本轮没有把性能优化当成停滞根因修复。

剩余性能验收包括桌面、图库、插件公共页、推荐插件组合、PERF-03 交互与失败恢复，以及真实 Safari/手机；完整 PERF-01/02/03 和 1.0 仍未通过。原始证据与截图保留在 `.runtime/performance-next/evidence/`，不把实验过程或截图二进制加入当前交付。
