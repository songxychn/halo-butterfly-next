# 更早 Halo 版本与兼容边界实测

2026-10-08。当前源码最低声明为 **`>=2.20.2`**，不设上限。本轮继续向下运行官方正式版，最低完成限定核心与搜索场景的版本为 **2.20.2**。该版仍有一次初始化失败记录，不能把最终通过写成“所有初始化尝试均通过”或完整上架验收。

市场最低版本应随最终提交包填 **2.20.2**，本轮未访问市场后台。评论仍要求 **Halo ≥2.26.0 / CommentWidget ≥3.3.2**；较低 Halo 正确拒绝该插件，主题隐藏旧版评论入口。公共插件页面布局是 Halo ≥2.26.0 的可选能力。

| --- | --- | --- |

| 2.20.21 | 测试探针 | 同上，通过 |
| 2.20.10 | 测试探针 | 同上，通过 |

| 2.20.0 | 测试探针，尚未运行到安装 | 初始化/登录响应失败；另一次 Basic API 诊断因官方默认禁用 Basic Auth 被拒绝，未证明主题核心不兼容 |

## 场景与环境

macOS arm64、Corretto 21.0.8、独立全新 H2、独立回环端口和自有无头 Chromium 会话。每个 JAR 与官方 Release 附件的 digest 或随包 `.jar.sha256` 校验文件比对。没有使用实验 JAR，也没有把旧版 JAR 放到固定 2.26.1 文件名下。

完整通过的核心场景：全新账户/数据库初始化；主题上传与启用；12 篇固定文章、1 个单页、分类/标签/菜单/站点配置；首页、分页、归档、年月归档、分类、分类详情、标签、标签详情、文章、单页共 10 条路由 HTTP 200 和 21 个主题资源；配置保存及重启后完整对象相等、内容与活动主题保留。

浏览器使用桌面 1440×1000 / 手机宽度 390×844，各亮/暗色共 4 组，核对首页与文章、实际桌面/移动菜单、模式持久化、hopscotch 高亮、系统等宽字体、无 Google Fonts 请求、代码折叠/展开和复制成功反馈。

固定 SearchWidget 1.7.1 校验摘要并启用；每组都等导航有限动画结束后真实点击搜索入口，检查函数确被点击触发、跨 Shadow DOM 的输入框挂载。较低 Halo 上传 CommentWidget 3.3.2 返回最低 Halo 版本拒绝，原有旧插件保持原版本；启动旧插件后评论入口仍隐藏。2.26.1 另实测 3.3.2 编辑器在滚动到评论区后挂载。停用插件后对应入口和评论挂载代码消失。

## 失败归因与测试适配

**2.19.3**：排除初始化、菜单和配置 API 差异后，在另一全新环境完成安装与相同夹具，首页仍 HTTP 500。模板 `views/aside` 对 `categoryFinder.listAll()` 的结果做列表筛选，日志为 `EL1015E: Cannot perform selection on input data of type 'reactor.core.publisher.FluxMap'`。文章可返回 200，不表示首页或整体核心兼容通过。[官方 2.20 模板增强源码](https://github.com/halo-dev/halo/blob/v2.20.0/application/src/main/java/run/halo/app/theme/dialect/EvaluationContextEnhancer.java)登记自 2.20.0 加入响应式方法结果转换；该差异支持边界解释，实际运行结果仍是验收依据。

**2.12.4**：同样排除初始化及配置 API 差异后，模板调用 `pluginFinder.available(String, String)`，日志报告 `EL1004E` 方法不存在。未通过 HTTP 检查，没有把后续浏览器或插件步骤记为通过。

**2.20.0/2.20.1**：问题发生在主题安装之前，属于本轮平台初始化/登录失败。官方 [#6865](https://github.com/halo-dev/halo/pull/6865)说明默认登录方式缺失会导致初始化后登录页无法正确渲染，[2.20.2 发行说明](https://github.com/halo-dev/halo/releases/tag/v2.20.2)包含该修复；与本轮现象吻合，但没有以实验修复 JAR 做因果对照。2.20.0 的 Basic 诊断被拒绝，是该版官方默认禁用 Basic Auth 的结果，不能当作主题错误。

**2.20.2 首次探针**：系统初始化 POST 返回 500，日志为 OpenAPI/JSONExtensionConverter 内的 `ConcurrentModificationException`，尚未安装主题。后续全新环境使用相同官方 JAR、探针、启动参数和流程通过；首次失败原样保留，未把它解释为脚本断言错误或已修复的产品问题。

测试适配仅在本地证据脚本内：旧版通过官方 JSON API 初始化与受支持的 HTTP Basic API；记录真实空初始内容，使用相同 12 篇文章和单页；旧 `/config` ConfigMap 的 JSON 字符串分组替代缺少的 `/json-config`，读取实际默认配置并保存实际资源；旧 MenuItem 不强求不存在的 `menuName`，另核对实际菜单链接。当前维护的 `scripts/lab/lab.py` 保持固定 2.26.1 基线。
