## 可重跑入口

独立合成站生成的浏览器会话保存为私有文件，不入库。以下命令只读取会话并检查页面和编辑器，不保存文章；匿名场景将会话文件替换为 `-`，期望替换为 `absent`。最后两个视口参数可改为 `390 844`。

```sh
bun scripts/post-edit/check-browser.mjs \
  http://127.0.0.1:<端口>/archives/<合成文章>/ \
  <合成会话-state.json> present .evidence/post-edit/check.json 1440 1000
```

后端准备沿用 `scripts/lab/lab.py` 的独立运行目录、进程归属检查、初始化、安装和播种；参考站准备失败后使用仓库已有的 `start(halo_only=True)` 与 `seed(reference=False)` 路径。角色测试使用官方 `/users` 创建合成账号，普通角色无额外角色，只读角色为 `role-template-view-posts`，文章管理为 `role-template-manage-posts`，权限结果由官方 `/users/-/permissions` 读取。开关和布局组合由一个测试进程串行修改并在 finally 恢复。

## 保留的失败与边界

1. Hexo 准备在 `bun run --bun --no-install hexo clean --silent` 退出 2，发生在 Halo 启动之前。本轮只继续 Halo 侧验证，没有固定双站通过结论。
2. 首轮工程门禁为 588 通过 / 1 失败：性能配置快照尚未包含新增开关。更新默认配置快照并增加超时测试后，完整门禁为 590 通过。
3. 合成账号的短时间连续登录触发 Halo 的 `rate-limit-exceeded` 重定向。保留账号和已有会话，等待窗口后仅补剩余登录；不修改 Halo 限流或主题代码。
4. 最初用编辑器 body 文本寻找文章标题的断言超时；标题实际位于输入框。后续改为检查输入值及编辑器路径，保留原断言失败，不视为产品失败。
