# 降低 Halo 最低版本的实测

2026-10-07。当前源码最低声明为 **`>=2.22.14`**，不设上限。最低实际验证版本是 **2.22.14**；本轮没有继续测更早版本，不把它称为技术上的绝对下限。市场最低版本须随最终提交包填写 **2.22.14**，本轮未读取或修改市场后台。

核心页面与搜索可在本轮测试的较低版本运行。评论入口仍以官方 **CommentWidget 3.3.2** 为最低基线，该插件要求 **Halo ≥2.26.0**；较低 Halo 拒绝安装，主题正确隐藏旧版评论入口。公共插件页面布局契约从 Halo 2.26.0 提供；官方说明它是[增量适配项，不影响主题安装和启用](https://docs.halo.run/developer-guide/theme/page-layout)，本轮旧版核心页面实测也正常。不能用该契约的引入版本推断整个主题的最低版本。

每次核心测试都使用真实官方 JAR，启动前校验官方 Release 的 SHA-256；macOS arm64、Corretto 21.0.8、独立全新 H2 数据目录与回环端口，无头 Chromium：

1. 初始化、上传、启用；安装目录 129 个文件逐字节等于所用 ZIP。记录真实最低声明与页面布局状态，旧版没有该状态字段时不要求 `SUPPORTED`。
2. 12 篇合成文章、1 个单页、分类、标签、菜单、站点配置，保留欢迎文章；核对 API 与实际桌面/移动菜单链接。
3. 首页、分页、归档、年月归档、分类、分类详情、标签、标签详情、文章、单页共 10 条路由 HTTP 200，无模板错误或未解析表达式；21 个主题资源检查。
4. 桌面 1440×1000、手机宽度 390×844，各亮/暗色共 4 组：首页与文章、模式保留、hopscotch 实际高亮、系统等宽字体、无 Google Fonts 请求、折叠/展开、复制成功反馈。
5. 保存配置并重启，核对配置、内容、活动主题及文章渲染。
6. 固定官方 SearchWidget 1.7.1 摘要，4 组真实点击打开搜索输入框。旧 Halo 记录 CommentWidget 3.3.2 安装拒绝响应，确认已有旧插件未被替换、启用旧插件时主题仍隐藏评论。2.26.1 另校验并启用 3.3.2，滚动到评论区后检查编辑器挂载。停用插件后搜索与评论入口/挂载代码消失。

## 原始记录与复现

原始脚本、截图、摘要、日志保留在 `.evidence/halo-lower-compatibility-20261007/`，运行数据在 `.runtime/halo-compatibility/lower-*`；均不进入安装包。探索最终目录为 `2.25.4-attempt2`、`2.24.2`、`2.23.3`、`2.22.14`，插件记录在各目录 `optional-final/`；实际候选在 `candidate/2.22.14`、`candidate/2.26.1`。测试进程与自有浏览器会话均关闭。

失败记录保留：旧版 MenuItem 不返回实验室原先要求的 `spec.menuName`，测试适配为核对旧版实际存在的排序、链接、标题、图标与子项，并另查实际菜单渲染；没有改主题。初次插件脚本过早点击仍在动画中的导航，诊断记录证明 `SearchWidget.open` 调用次数为 0。等待加载结束及有限 CSS 动画完成后，同样的真实点击在四组场景均调用入口并挂载输入框；没有改主题、插件或延长等待预算。诊断中的直接调用只用于定位，最终通过结果均来自实际点击。

复现使用既有 `scripts/lab/lab.py` 的 Client/install/seed（`reference=False`）和 `scripts/smoke.mjs`；单独启动对应真实 JAR，不替换固定实验室 2.26.1 JAR 冒充版本。用独立空目录与空闲端口，核对 JSON 中的包/JAR 摘要，依次执行以上场景及重启检查。
