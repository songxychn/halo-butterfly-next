# 最低 Halo 版本与实际兼容验证

2026-10-07。按维护者要求，当前源码只声明最低版本 **`>=2.26.0`**，不设置未来版本上限。市场最低版本字段应随最终提交包填写 **2.26.0**；本轮未访问或修改市场后台。

最低已验证正式版本为 **2.26.0**。主题提供的[公共页面布局契约](https://docs.halo.run/developer-guide/theme/page-layout)从 2.26.0 提供，固定 CommentWidget 3.3.2 的官方包也要求 Halo `>=2.26.0`。本轮实际在该最低版本执行安装与运行检查；未测试更早 Halo，也不判断更早版本所有核心页面一定无法运行。

- `bun run verify` 通过：583 个测试、类型检查、对齐检查、构建及 129 文件包检查。包检查只接受 `>=最低正式版本` 格式。

每个 JAR 在执行前与官方 Release 公布的 SHA-256 比对；没有使用实验修复 JAR，也没有把其他版本 JAR 放入 2.26.1 文件名下。固定对照实验室的 2.26.1 基线保持原样。

每版检查：

1. 全新数据库初始化、上传与启用同一 ZIP；安装目录 **129 个文件逐字节等于 ZIP**；实际 Theme 资源读取最低声明，`status.pageLayout.state` 为 `SUPPORTED`。
2. 12 篇固定合成文章、1 个单页及分类/标签/菜单/站点配置；保留初始欢迎文章。API 核对内容、发布时间及菜单。
3. 首页、分页、归档、年月归档、分类与分类详情、标签与标签详情、文章、单页共 **10 条路由** HTTP 200，无模板错误及未解析表达式；**21 个主题资源 URL** 状态与内容检查通过。
4. 保存 hopscotch 亮暗配置；桌面 1440×1000 / 手机宽度 390×844，各亮色和暗色，共 **4 组**：首页与文章、模式保留、实际代码高亮、系统等宽字体、无 Google Fonts 请求、折叠与再展开、复制成功反馈。
5. 重启真实 Halo；活动主题、上述设置及合成内容保留，文章仍渲染主题。
6. 校验并启用官方 SearchWidget **1.7.1** / CommentWidget **3.3.2**。4 组浏览器场景检查实际搜索入口打开与输入框挂载、滚动到评论区后实际编辑器挂载；停用两个插件后搜索和评论入口消失。评论系统配置恢复，测试进程及自有浏览器会话关闭。

## 原始记录与脚本修正

本机原始日志、截图、API 运行摘要和执行脚本保留在 `.evidence/halo-compatibility-20261007/`；各版本核心记录为 `2.26.0-attempt2`、`2.26.1-attempt2`、`2.27.0-beta.1`，插件最终记录为各目录下的 `plugins-final/`。该目录及运行数据不进入安装包。JSON 保留具体路径和运行结果，不包含凭据或会话 cookie。

测试脚本初次错误记录保留：核心检查曾读取不存在的 `code` 设置分组，修正为实际 `render`；搜索曾用普通 DOM 查询忽略 Shadow DOM；评论曾在滚动到评论区之前等待挂载，且未查询编辑器的多层 Shadow DOM。限定诊断确认 CommentWidget 3.3.2 的 `init` 使用 IntersectionObserver，模块请求成功，无前端异常；按实际使用流程滚动并跨 Shadow DOM 查询后通过。初始全局评论设置已为启用，重新设置该字段不是修复原因。上述修正未修改主题或插件代码，也没有延长等待预算。

复现方法：校验 JSON 中的各官方 JAR 摘要，在独立空 H2 目录和空闲回环端口启动实际 JAR；使用现有 `scripts/lab/lab.py` 的 Client、install、seed（`reference=False`）执行初始化及夹具；运行 `scripts/smoke.mjs` 的 JSON 路由列表；按以上 4 组视口与模式检查；重启并核对配置。固定实验室 CLI 自带的 JAR 校验仍只允许 2.26.1，不通过替换其固定文件冒充跨版本测试。

## 验证边界

这是一轮有明确范围的兼容验证，不是完整上架或 1.0 验收。最低版本声明不会自动使尚未发布的 Halo 获得测试通过结论。2.27.0-beta.1 的结果不能写成“正式 2.27.0 已支持”。

复制只核对真实成功反馈，未读回剪贴板字节。搜索未重做结果查询、焦点恢复与完整键盘验收；评论未重做提交、回复、审核和角色矩阵。只检查公共布局的真实资源状态，未重做合成布局探针生命周期或生态插件页面。没有实际 Android/iOS、Firefox/WebKit、多操作系统、性能、升级回退或全部配置组合结论。

#338 资源加载及 #313 搜索焦点仍按原始记录保留；本轮有限 Chromium 场景成功不证明这些问题已解决。正式市场候选仍须执行[首发验收清单](../../APP-STORE-FIRST-RELEASE.md)，并把最终包的最低版本同步到市场。
