# 维护路线与对齐清单

## 固定基准

| 项目 | 首轮基准 | 用途 |
| --- | --- | --- |
| Halo | 2.26.1 | 实际测试运行环境；初期兼容声明限定在 2.26 系列 |
| Halo Butterfly 源码 | `de9046b47a8e04c3db85170e356dde9e68f26d77`（源码标记 2.0.7） | 保留完整 Git 历史的维护起点 |
| Halo Butterfly 已发布版 | 2.0.5 | 旧用户配置迁移入口 |
| Hexo Butterfly | 5.7.0，`f223b1888b42b2b336068e6c959ed90a3cd7c8f3` | 首轮外观与功能对齐目标 |

参考：[原 Halo 移植项目](https://github.com/dhjddcn/halo-theme-butterfly)、[Hexo Butterfly 5.7.0](https://github.com/jerryc127/hexo-theme-butterfly/tree/5.7.0)、[Halo 主题开发文档](https://docs.halo.run/developer-guide/theme/prepare)。上游出现新版本时先登记差异，再决定是否移动基准，避免开发目标不断变化。

## 分阶段交付

| 阶段 | 范围 | 完成条件 |
| --- | --- | --- |
| M0 / 0.1 alpha | 独立主题身份、可重复构建、迁移工具、真实 Halo 基础可用性 | 能独立安装/升级；旧配置不被覆盖；核心页面和资源实际可用；留有验收记录 |
| M1 / 0.2 | 首页、导航、文章列表、文章排版、侧栏、深色模式、手机布局 | 与 5.7.0 固定样例在相同内容/视口/配置下逐项比对；相关交互通过 |
| M2 / 0.3 | 搜索、评论、链接/图库/瞬间及 Halo 2.26 插件页面公共布局 | 插件有无、启停和公共布局都验证；明确支持版本与替代能力 |
| M3 / 私有 RC | 全部适用 5.7.0 能力、配置文档、升级回退、浏览器/真机、无障碍与性能、供应资源 | [1.0 工程验收合同](RELEASE-ACCEPTANCE.md)全部必需场景通过；精确提交独立审查与 CI、实际私有候选包证据完整 |
| 1.0 正式发布 | 公开反馈、仓库开放方案、维护者最终验收与稳定发布 | 保留原公开反馈和公开仓库 CI 条件；公开仓库、历史处理及正式 1.0 由用户确认，不由私有 RC 自动触发 |

完整能力状态以 [5.7.0 功能矩阵](parity/MATRIX.md)及其 `matrix.json` 真相源为准；双站重建方式见 [对照环境](COMPARISON-LAB.md)。以下为接手时的摘要，不替代逐项验收。上游默认关闭项仍须盘点，平台差异涉及实质取舍时交由用户确认。

## 当前差异状态

| 功能 | 当前实现 | 5.7.0 对齐状态 |
| --- | --- | --- |
| 首页首屏、导航、列表、分页 | 继承 Halo 版，修正资源和默认配置 | 待视觉比对 |
| 文章、标题、目录、代码工具栏 | 继承 Halo 版并修复基础行为 | 待逐项比对 |
| 手机菜单、主题模式 | 基础行为修复 | 待完整布局比对 |
| 分类、标签、归档、自定义页面 | 保留 Halo 页面 | 待逐项比对 |
| 搜索、评论 | Halo 插件接入与停用回退 | 待完整交互和版本矩阵 |
| 友链、图库、瞬间 | 保留原有模板 | 未做插件集成验收 |
| Halo 2.26 插件公共布局 | 原主题未实现新布局契约 | 待实现，勿宣称支持 |
| Hexo 标签插件、数学公式、扩展功能 | 需逐项判断主题/编辑器/插件负责范围 | 待能力映射 |

首轮没有宣称全面对齐 5.7.0。M1 开始时建立独立 Hexo 参考站与固定内容夹具，截图差异必须结合交互检查，不能只按相似度判断兼容性。

## 长期维护方式

采用“上游差异 issue → 单功能 PR → 实际页面验收 → 版本说明”的流程。兼容范围只在真实验证后扩大。核心资源随主题版本分发，插件按需接入；将 Halo 数据读取与页面表现逐步分开，降低后续上游移植成本。
