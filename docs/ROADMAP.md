# 1.0 收尾计划

当前产品范围以 [DEC-10](parity/DEC-10-THEME-SCOPE.md) 为准。目标是可安装、可升级、可回退的 Halo Butterfly 主题；上游矩阵用于记录差异，不是逐项复刻的发布清单。

1. 完成删减后 `bun run verify`，核对包内容、许可证与配置迁移；清除已移除功能的现行使用说明。
2. 用同一删减后包在官方 Halo 2.27.1 检查安装、旧配置升级、原生导航/历史返回、文章与单页、阅读增强、官方插件及回退。新包不能继承旧候选全部通过的结论。
3. 独立审查最终源码及 CI，冻结源码和 ZIP 摘要，更新发布说明和安装/回退说明。核实发布授权门禁及公开 demo 的发布文案。
4. 维护者明确授权后才创建正式标签、发布包和更新公网 demo。

真实 Safari/手机、完整辅助技术、所有编辑器/插件组合等既有边界继续公开说明。PWA 等未承诺能力不作为本轮补齐目标。删除的 PJAX、外部服务和全站浏览器统计不安排恢复；新需求需单独评估。

历史验收保留在 `docs/validation/`，其包摘要和适用范围不能由更新路线图自动改变。
