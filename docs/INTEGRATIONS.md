# 外部服务边界

按 [DEC-10](parity/DEC-10-THEME-SCOPE.md)，主题不再内置分析、聊天、广告、不蒜子、Share.js/AddToAny 或远程字幕服务；对应设置、SDK 加载和专属验收脚本已移除。

搜索、评论、友链、图库和瞬间仍使用 Halo 官方插件。分享使用浏览器系统分享或复制链接，阅读量取 Halo 原生数据。资源地址配置见[资源说明](RESOURCE-SOURCES.md)。

站点如需分析等服务，可自行通过平台或已有 head/bottom 注入能力管理。主题不为这些手写脚本提供提供方适配或服务可用性承诺。旧配置升级前运行离线迁移工具并查看 `removed-feature` 报告；注入区脚本需自行检查。
