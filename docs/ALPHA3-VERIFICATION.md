## 失败与剩余限制

### 搜索焦点：已批准的公开 alpha 例外

最终搜索/评论/权限检查共 26 项：17 通过、9 失败。其中 8 项是官方 SearchWidget 1.7.1 经 Escape/遮罩关闭后不返回入口焦点；维护者已批准明确披露后仅对公开 alpha 放行，原始失败与 1.0 失败门禁保留。核心页面另记录 4 组首页 Escape 返回焦点为 false，没有将其改记通过。详见[搜索焦点裁定](SEARCH-FOCUS-DECISION.md)。

### 资源加载超时：尚未解决或批准例外

最终插件检查的第 9 个失败是手机亮色搜索导航：目标文章已选中，但 DOMContentLoaded 等待 30 秒失败，现场 readyState=loading，Prism One Light CSS 未收到响应。它不属于搜索关闭焦点例外。

此前 `de2788c` 包（SHA-256 `c0e256972493987dc522036cc3640c69647b0f4e9d254ca52a86441b52947b5a`）macOS 原生三引擎矩阵为 Chromium 40/40、Firefox 38/40、WebKit 40/40。Linux 旧包对照也出现资源 pending 和就绪/截图超时；其早期运行 Chromium 未能启动，不能算作运行过 120 个页面。各次失败及环境诊断分别保留，不能归因成单纯 macOS 问题，或合并不同源码/平台的通过次数。

控制实验表明连接复用是调查方向，尚不能确认每个浏览器失败的根因。连接关闭、资源替换、重试或单次成功均不能清除原生失败。本记录没有允许通过修改服务端依赖来规避 Halo 2.26.1 固定平台，也没有授予新增发布例外。

### 性能：有改善，仍未达成完整合同

Lighthouse 13.4.1 / Chrome 153.0.8010.12，模拟节流，每页面/设备单样本，SearchWidget 和 CommentWidget 启用。初始 `de2788c` 长文章移动结果 LCP 5949 ms / FCP 4899 ms / TBT 182 ms；优化后 `9593d49` 为 LCP 4654 ms / FCP 3004 ms / TBT 97 ms / CLS 0.000129。同步 Prism 阻塞已处理，剩余模拟关键路径涉及评论插件资源和图标字体；这不是对各资源收益的保证。

最终 `776958ad` 增加当前阅读代码块不被初始折叠的修正，未另取性能样本；上述性能数字继续归属于 `9593d49`。模拟 LCP 不等于本地实际等待时间，不是五样本中位数、真实设备测试或完整 PERF 合同通过。初始首页/桌面诊断同样仅作历史样本，不能冒称最终包所有页面性能达标。
