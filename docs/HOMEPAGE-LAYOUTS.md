# 首页文章布局

主题设置 → 首页 →「首页文章布局」提供 Butterfly 5.7.0 的七种排列。首屏、导航、侧栏继续独立配置。

| 编号 | 布局 | 桌面排列 |
| --- | --- | --- |
| 1 | 固定左图 | 左侧封面、右侧文字 |
| 2 | 固定右图 | 左侧文字、右侧封面 |
| 3 | 左右交替 | 第一篇左图，之后按文章顺序交替 |
| 4 | 单列上图下文 | 全宽封面，下方文章信息 |
| 5 | 单列图上叠字 | 文章信息叠在带遮罩的封面上 |
| 6 | 瀑布流上图下文 | 多列卡片，上方封面、下方文字 |
| 7 | 瀑布流图上叠字 | 多列卡片，文章信息叠在封面上 |

1–3 的卡片高 16.8em，封面占 42%；4/6 封面高 230px；5/7 封面高 17em，带上游 40% 黑色遮罩和 3px 背景模糊。768px 及以下为单列，1–3 变为上图下文，5/7 保留叠字；2000px 及以上，6/7 为三列，1–3 卡片高 18.8em。6/7 使用与固定上游相同的 InfiniteGrid 4.13.0，间距横向 10px、纵向 20px，只在这两种首页布局加载本地脚本。

显式选择任意一种布局时，摘要按「首页列表摘要」的 method/length 渲染；标题和摘要最多显示两行。封面关闭或没有可用封面时，回退为普通文字卡片。置顶文章在标题前显示图标。

## 升级与回退

新增 `index.index_layout` 默认留空。未选择时沿用既有 `index.post_layout`：`list` 对应 3，`tile` 对应 6，并继续不输出摘要。新安装的旧字段默认 `list`，因此实际默认仍为 3。无效的新布局值也沿用旧选择，避免输出任意 CSS 类。

选择 1–7 后，新字段优先；旧字段保留在 ConfigMap 中，回退旧主题包仍能读取原来的 list/tile。后台在新布局留空时显示旧布局选项。选择 6 与沿用旧平铺的区别是前者服从摘要设置；这不会强行改变旧平铺的摘要行为。

本项只对首页生效；分类、标签继续使用既有共享列表。七种实现不等于完整 1.0 已验收，真实 Safari、真机和全部合同场景仍需独立记录。
