## 本轮变化

- 明亮文章封面元信息、评论计数、卡片元信息、作者按钮、标签云和页脚可读性改善；页脚图片上的键盘焦点位于不透明底板内。
- 开启顶图遮罩时加强导航局部遮罩并向下渐隐。分页当前页、悬停文字和焦点框对比提高；文章列表标题悬停采用可读的正文链接色，元信息链接保留悬停对比并增加常驻下划线与内侧焦点框。
- 采用 MIT Viewer.js 1.14.0 替代旧 Fancyapps 灯箱，保留主要图片查看操作；普通外链/下载链接保持原生语义。外观不承诺与旧灯箱逐像素一致。
- 提高正文链接、引用、版权字段与默认 One Light/One Dark 高亮对比度；可滚动代码块增加键盘焦点入口。
- 修复空分类站点图表异常；修复代码折叠/展开按钮被裁剪；四种 Loading 在正文 DOM 就绪后退出。
- 可选文章与列表评论数默认关闭，并遵守插件版本、全局及逐篇评论权限。
- 使用原生光标、清理不再使用的继承素材，随发行物保留第三方许可和改写来源。

详细改动见[变更记录](../CHANGELOG.md)。下方已知限制和最终验证状态与这些源码改动分别记录。

## 固定支持和已知问题

实际测试 Halo 2.26.1、SearchWidget 1.7.1、CommentWidget 3.3.2；元数据范围不代表所有版本组合均已验证。升级前先[备份并演练回退](INSTALL-UPGRADE.md)，同 ID 更新保留主题配置；旧主题迁移见[迁移说明](MIGRATION.md)。

公开 alpha 接受且必须披露：SearchWidget 1.7.1 关闭后焦点不返回原入口。键盘用户需重新 Tab 导航；检查仍记失败，用户批准的例外只针对公开 alpha，详见[决策记录](SEARCH-FOCUS-DECISION.md)。

关闭顶图遮罩后，明亮图片上的导航与大标题仍可能对比不足；保留遮罩或选择合适封面。自定义代码高亮主题、CSS和注入代码，正文扩展、完整插件生态、真实 Safari、真实手机、屏幕阅读器与完整性能/1.0矩阵没有全面通过声明。继承模板的存在不代表已验证。回退原始 alpha.2 时须注意关闭文章顶图的旧 JS 缺陷。

## 验证边界

已有开发候选完成局部修复、合成站升级回退和真正全新数据库安装检查，但源提交与包内容各不相同。它们是冻结评估的输入，**不能合并措辞为最终 alpha.3 已验证**。冻结后需检查差异，重新验证受影响路径，并填写最终材料身份、CI、可重复构建及独立审查。无头浏览器或桌面手机视口不是实机测试。

问题反馈只提交脱敏复现：版本、步骤、预期/实际行为、必要日志或截图。请勿提交密码、Token、Cookie、原始数据库或个人配置。
