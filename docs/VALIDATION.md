# 0.1.0-alpha.1 首轮验收

日期：2026-09-06。以下记录来自独立本地测试站，不涉及正式博客数据。

## 环境与产物

- Halo 2.26.1 官方 JAR，Corretto 25，本地 H2。
- Node.js 24.19.0，pnpm 11.19.0；锁文件安装使用 `--frozen-lockfile --ignore-scripts`。
- 独立无头 Chromium，桌面 1440×1000、手机 390×844。没有连接用户现有浏览器。
- 12 篇合成测试文章、1 篇 Halo 初始文章、合成分类/标签及一个自定义页面。
- 安装包：`halo-butterfly-next-0.1.0-alpha.1.zip`，2,734,240 字节、117 个文件。
- SHA-256：`92e7bfeff60a753aeef2cbcd57f1d148e5f589e5fd3b6df3eec27944b836800a`。
