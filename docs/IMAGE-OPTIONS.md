# 顶图配置

顶图是页面标题区域的背景；列表封面和正文图片继续使用原有配置。

## 开关

主题设置 →「顶图」的「全局关闭顶图」优先于全部页面类型和单篇设置，默认关闭此选项。启用它不会关闭列表封面；页面标题留在内容区，文章元信息只显示一次。主题公共插件布局本来没有顶图，保持原样。

文章和自定义页面的自定义元数据新增「显示顶图」三态：跟随全局、显示、隐藏。文章跟随文章设置的「启用第一屏」，单页跟随 `single.enable_above`；显式「显示」可以覆盖页面类型的关闭，但不能覆盖全局关闭。

## 图片来源

不新增文章或单页的独立顶图字段。文章始终优先复用 Halo 原生 `post.spec.cover`，单页使用 `singlePage.spec.cover`。

| 页面 | 选图优先级 |
| --- | --- |
| 文章 | 原生文章封面 → 默认顶图 → 纯色 |
| 自定义页面 | 原生页面封面 → 默认顶图 → 纯色 |
| 分类详情 | 原生分类封面 → 分类背景 → 默认顶图 → 纯色 |
| 标签详情 | 原生标签封面 → 标签背景 → 默认顶图 → 纯色 |
| 首页、归档、分类/标签总览 | 对应页面背景 → 默认顶图 → 纯色 |
| 友链、图库、瞬间 | 默认顶图 → 纯色 |

分类和标签封面在 Halo 对应的管理页面配置；详情页同时显示该分类/标签名称。总览页不读取某个分类或标签的封面。

「默认顶图」默认为空。首页、归档、分类和标签背景可清空，清空后继承默认顶图。现有背景默认值及已保存的图片不被覆盖。

图片无法加载时，尝试默认顶图；同一个 URL 不重复尝试。默认顶图也失败时移除背景图片，保留纯色区域、标题和导航。此规则不改正文及列表图片的失败图，不对第三方随机服务作可用性承诺。

## 颜色、渐变与页脚继承

默认顶图和首页/归档/分类/标签背景支持图片 URL，也支持 CSS 颜色（如 `#29466b`）、渐变（如 `linear-gradient(135deg, #29466b, #68a)`）和合法的 `background` 简写。通过浏览器 CSSOM 设置单个属性，配置不会拼接进样式表。颜色和渐变不按图片 URL 发起探测或 preload。原生文章/单页封面继续优先，仍不新增独立顶图字段。

页脚背景为空或 `false` 时保留默认外观；填写 `true` 继承当前页选定的顶图，无当前值时使用默认顶图；也可单独填写上述 URL / CSS 值。遮罩仍由 `mask.footer` 控制。背景是脚本渐进增强，脚本关闭时正文和页脚内容仍完整可读。

## 升级与验证边界

当前配置统一采用上述优先级，不读取文章随机图或单页首页图作为隐式回退。`single.enable_above` 默认 true，友链/图库/瞬间使用独立 `image.other_pages_above`（默认 true）；首页开关不再影响它们。全局关闭和逐篇三态仍保留，列表随机封面不改变。

旧配置通过离线工具转换开关，报告跨页面图片继承的取消，不自动复制首页图片到全局默认顶图。

回退旧包后，旧包忽略新分组和元数据，文章、单页及分类标签数据无需迁移。请保留升级前的主题包与配置。

固定上游依据为 Butterfly 5.7.0 `layout/includes/header/index.pug`。文章原生封面复用按本项目适配保留，不把 Hexo 的独立 `page.top_img` 图片字段搬入 Halo。完整双站、Safari、真机及 1.0 合同仍须另外验收。

在独立合成实验室安装候选后，可用 `LAB_RUNTIME=/绝对路径/实验室 HALO_PORT=实验室端口 HEXO_PORT=参考端口 python3 scripts/images/validate.py` 重跑限定场景。需要 agent-browser；脚本只启动自己的无头会话，先核验实验室所有权，保存原始配置，最后恢复配置和内容覆盖字段。结果写在实验室上级的 `top-image-validation/`，凭据及原始配置不入库。`--only native-category native-post post-hidden` 可复核这三组场景；没有执行任何匹配场景时返回失败。
