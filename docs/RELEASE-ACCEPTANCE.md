## 2. 功能矩阵与适用性闭环

[功能矩阵](parity/MATRIX.md)由 `docs/parity/matrix.json` 维护；上游清单为 `docs/parity/upstream-5.7.0.json`。矩阵必须覆盖固定源码的配置叶项、页面模板、前台交互、标签扩展、渲染过滤器、资源加载与第三方接入，不能只盘点当前 Halo 已有选项。上游默认关闭的功能也在盘点范围内。

每项至少记录：稳定能力 ID、上游提交/文件/符号或配置路径、用户可见语义、Halo 实现或依赖方案、依赖版本、配置映射、关联 issue/PR、本合同场景 ID、专属断言、实际证据及状态。一个合同场景可支撑多个条目，但条目仍须逐项证明；“文章页通过”不能覆盖数学公式、Tabs，或仍适用的搜索入口/评论挂载/计数等条目。DEC-01 已确认不把上游每一家搜索引擎或评论 SDK 当作独立 1.0 能力。

| 状态 | 使用条件 |
| --- | --- |
| 未盘点 / 待决策 | 尚缺来源、适用性或实质映射决定；阻止工程完成 |
| 待实现 / 进行中 | 已有明确要求但未完成实现；阻止工程完成 |
| 待验证 / 验证失败 | 缺少实际证据或断言未通过；阻止工程完成 |
| 待独立审查 / 待 CI | 作者验证后仍未完成独立门禁；阻止条目关闭 |
| 已验收 | 专属断言、适用交叉场景和对应提交审查/CI 均通过，证据可定位 |
| 不适用（有依据） | 仅限两类：确属 Hexo 构建机制、在 Halo 没有对应用户能力；或维护者已在对应 DEC issue 书面裁定的提供方缩减/平台替代。矩阵状态为 `not-applicable`，须含 `decision`（issue、日期、选项、理由、替代方案）。运行器未实现、账户缺失、真机缺失、外部服务失效、平台 API 不足都不是“不适用”。未经裁定不得用此状态绕过 |

如果矩阵采用其他状态代码，必须在矩阵文档写出与本表的一一对应关系。停止支持、延期到 1.1、缩减提供方、放弃移动端或以截图替代交互，均属于需用户决定的实质取舍。DEC-01 只授权搜索/评论提供方的 `not-applicable`；DEC-02 将标签映射为等效 HTML，不把 `tag:*` 标为不适用。

完成算法：上游清单每项都有矩阵映射，矩阵每项有明确适用结论；所有适用条目为已验收，所有不适用条目有上述依据；所有本合同必需场景通过；不存在未裁定差异、失效证据或未处理审查意见。进度分母使用全部适用条目。`not-applicable` 与经 DEC 裁定延期到后续版本的 `blocked`（`blocker.phase` 为目标版本）均在 RC 总表单列，不计入当前工程终点分母，也不得记为已验收；不得把未裁定项标为延期或不适用。待决策数单列，不通过删除困难条目提高完成率。

## 4. 页面、配置与交互场景

## 5. Halo 与插件边界

Halo 的 [插件集成](https://docs.halo.run/developer-guide/theme/plugin-integration)规定插件能力按可用性和必要版本检查，评论通过 `haloCommentEnabled` 组合条件接入，页脚保留 `halo:footer` 扩展点。[页面布局契约](https://docs.halo.run/developer-guide/theme/page-layout)从 2.26.0 提供 `templates/layout.html` 中的 `html(head, content)`，安装后可读 `Theme.status.pageLayout`。这些官方规则是适配依据，真实 2.26.1 的运行结果才是项目通过证据。

每个依赖登记实际插件 `metadata.name`、版本、来源、包 SHA-256、所需最低版本、公开 Finder/API/模板契约、负责的能力 ID。至少覆盖 SearchWidget、CommentWidget、语法高亮、友链、图库、瞬间，以及矩阵最终采用的内容扩展/SEO 等插件。1.0 搜索与评论的主题支持面仅为官方 `PluginSearchWidget` 与 `PluginCommentWidget`（DEC-01）；精确版本与 JAR SHA 在搜索/评论实验中锁定后写入矩阵依赖，未锁定前这两项保持未完成。没有选定兼容实现的其他能力继续待实现或待决策。

| ID | 执行场景与成功条件 | 所需证据 |
| --- | --- | --- |
| PLG-01 | 每个可选插件分别未安装、安装停用、满足版本启用、不满足最低版本测试；入口随可用性变化，无越界 Finder/API/全局变量调用；恢复启用后能力恢复 | 4 种状态的插件资源摘要、页面与网络/控制台结果；版本不满足可用实际旧版或隔离契约夹具，标清后者非真实版本兼容证据 |
