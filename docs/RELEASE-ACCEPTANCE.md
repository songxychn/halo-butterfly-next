# 1.0 发布验收要求

版本：2026-10-27 / v1.14，依据维护者批准的 [DEC-09](parity/DEC-09-RELEASE-CLOSURE.md)。本文件只列当前有效要求；历史合同及修订见[清理前快照](https://github.com/songxychn/halo-butterfly-next/blob/409e79cc6e4bc027b35d2972b8854efcfbc61b28/docs/RELEASE-ACCEPTANCE.md)。维护者已授权 PR #432 经独立审查和 CI 通过后合并；本轮仍不打 tag、不发布。

## 发布阻塞的判定

- 声明支持范围内，已知未修复的严重安全/隐私或数据损坏问题、核心页面无法阅读、核心导航或承诺的主题插件入口无法使用。
- 最终候选的核心证据、安装/升级/回退、构建/许可、独立审查或必需 CI 缺失。
- 版本、依赖或已知限制说明不准确，会使用户误解实际交付能力。

上游问题若造成上述影响仍可阻塞；缺少全组合覆盖、矩阵不是 verified 或未穷尽插件内部机制，不自动构成阻塞。新增阻塞须有具体用户影响、适用组合、证据及关闭条件。

## 兼容与已知限制

主题最低 Halo 版本保持 `>=2.20.2`；声明不代表每个版本/插件组合均实测。当前固定运行组合使用未经修改的 Halo 2.27.1、CommentWidget 3.3.2，其他插件依各自官方版本要求。不得以定制插件、连接绕行或提高最低版本来制造通过。

WebKit 图片草稿刷新、编辑器属性保留、原生图片初始加载及平台语义差异按 [DEC-09 的 K1–K4](parity/DEC-09-RELEASE-CLOSURE.md#已知限制披露不要求在-10-前修完) 披露。全量插件业务、长尾配置/映射和其他编辑器覆盖为后续改进。实际 Safari/真机/完整无障碍、真实账户和其他既有延期沿用原决定，不恢复为发布门禁。

## 证据与执行边界

每份实际验收记录绑定 source SHA、安装包 SHA-256、平台/插件/工具版本、范围、结果及时间；失败与恢复记录分开。工具失败不能直接认作主题缺陷，隔离对照不能冒充完整用户流程。安全清理仍须验证自有资源归属，不能删除无法归属的对象。

小型脱敏报告保留在仓库；原始大报告/trace 的位置和哈希应可追溯。不得提交凭据、Cookie、数据库或真实用户内容。所有历史记录保持受测包归属；文档/工具变化不自动使产品证据失效，但必须分析实际影响。

当前唯一自然回收观察 `ac230b71aa8ba2fd7342` 按原期限继续到清理恢复完成；不另起批次、不改时间、不重启服务、不抢锁。它是已启动工作的收尾，不是新增发布门禁。观察结束后停止自动跟进，失败按实际风险分级，不自动开新支线。
