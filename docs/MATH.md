# 数学公式（KaTeX 插件适配）

本主题适配 Halo 官方 KaTeX 插件渲染行内与块级数学公式，并针对阅读体验做了以下增强：

- **长公式局部滚动**：超宽块级公式在容器内横向滚动，不撑破正文排版。
- **一键复制 TeX 源码**：开启后可在公式右上角点击复制原始 TeX 表达式。
- **亮暗模式与可读性**：公式颜色自动跟随浅色/深色主题切换，保留原生 MathML 语义。
- **粒度控制**：支持全局开关以及在单篇文章/自定义页面元数据中按篇覆盖。

## 使用步骤

1. 在 Halo 插件市场安装并启用官方 KaTeX 插件。
2. 在主题设置中启用数学公式增强选项（按需开启 TeX 复制与隐藏滚动条）。
3. 在文章中使用标准行内 `$...$` 或块级 `$$...$$` 语法书写公式。
