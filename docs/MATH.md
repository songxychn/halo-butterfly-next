# 数学公式

主题适配 Halo KaTeX 插件保存的公式，不附带数学渲染库。插件负责编辑器录入及渲染，主题保留 MathML 语义和 TeX 注解，在外围提供布局、滚动和复制控件。范围裁定见 [DEC-07](MATH-RENDERING-DECISION.md)。

## 安装与编辑

已固定联调提供方：[Halo KaTeX 3.0.0](https://github.com/halo-sigs/plugin-katex/releases/tag/v3.0.0)，`metadata.name=plugin-katex`，要求 Halo ≥2.22.2；内置 KaTeX 0.16.25。JAR 哈希见 [版本锁](../fixtures/math/versions.json)。可选插件的最低版本不会改变主题自身的 Halo ≥2.20.2 声明；低于插件要求时应升级 Halo 后再安装插件。

在 Halo 插件管理中安装并启用插件，用默认编辑器的公式菜单插入行内/块级公式。**默认编辑器保持插件“前台渲染”关闭**：它已经保存 MathML，开启再次渲染会造成重复处理。主题不扫描正文中的 `$...$`、不转换代码块，也不改写作者公式。

插件 3.0.0 的编辑器输出为 `span.katex-inline` / `div.katex-block`，内部 MathML 通过 `annotation[encoding="application/x-tex"]` 保存源码。主题也识别独立 MathML、`.katex-display` 以及明确的原始公式节点 `.math-inline` / `.math-display` / `[math-inline]` / `[math-display]`。原始节点仍由插件渲染；缺少插件或渲染失败时保留原文，主题不会自行完成渲染。

其他编辑器如需插件前台渲染，必须配置仅匹配原始公式的选择器，例如 `.math-inline`、`.math-display`，不要包含默认编辑器已经渲染的节点。插件 3.0.0 的默认行内选择器含尾部双引号，需手动修正；本次仅对默认编辑器**保存格式**做实际联调，未验收其他编辑器的录入/保存流程。

## 配置与阅读

| 设置 | 默认 | 行为 |
| --- | --- | --- |
| 数学公式 → 显示公式 (`math.enable`) | 开启 | 关闭时将有源码的公式切换为字面 TeX 显示；原 MathML 保留在 DOM 中。无法提取源码的公式保持原样。 |
| 文章/单页元数据 `katex` | `inherit` | `true`/`false` 优先于全局；未填写、清空或 `inherit` 跟随全局。 |
| 复制 TeX (`math.copy_tex`) | 开启 | 有非空源码的公式显示 TeX 按钮；完整选中单个公式节点复制时输出原 TeX，部分选择和混合正文选择沿用浏览器行为。 |
| 隐藏长公式滚动条 (`math.hide_scrollbar`) | 关闭 | 仅隐藏滚动条，仍支持触摸/鼠标和键盘横向滚动。 |

旧配置缺少数学组时默认显示公式并允许复制。全局/逐篇开关只改变前台阅读表示，**不关闭插件、不取消它全站注入的资源或渲染调用**。这仍是 1.0 按需加载验收的未满足项。

长行内/块级公式均限制在正文宽度内，出现溢出时容器可聚焦并用方向键、Home/End 滚动。控件继承亮暗文本颜色。复制按钮提供名称、可见焦点和状态反馈；剪贴板被拒绝时显示失败提示，保留可选择的内容。主题从不把 TeX 当 HTML 插入。

编号以作者显式 `\tag{7}` 等所选版本支持的写法展示；主题不自动编号。`MathJax` 的 `all/ams/none` 与右键菜单已按 DEC-07 移出 1.0。KaTeX 支持范围参照 [0.16.25 源码支持表](https://github.com/KaTeX/KaTeX/blob/v0.16.25/docs/support_table.md)，不能认为 MathJax 内容可无损转换。非法命令由插件/KaTeX 输出可见错误或源码，不应删除正文。

## 回退与边界

插件未安装/停用时，已经保存的 MathML 仍由浏览器读取，主题可从注解复制；原始未渲染节点显示 TeX，不会阻塞正文。MathML 阅读不依赖前台 KaTeX JS。插件 3.0.0 会在无公式页面也加载 CSS；启用插件前台渲染后还会全站加载 JS，并且原始选择器渲染错误不由主题接管。

本实现提供主题适配，不构成完整 PLG-06/EXT-02 验收。编辑器 UI 流程、其他编辑器、不满足版本的实际安装拒绝、真实 Safari/移动设备、真实屏幕阅读器、独立审查仍需验证。专项复现方法和证据见 [验证记录](validation/2026-10-11/katex.md)。
