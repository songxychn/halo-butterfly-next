# 外观、侧边栏与图片配置

本主题提供丰富的外观与布局自定义能力，可在 Halo 控制台的主题设置中直接调整。

## 外观与亮暗配色

- **色彩模式**：支持默认浅色、默认深色、跟随系统（`system`）以及按时段自动切换深色模式。
- **主题配色与字体**：支持自定义主色、链接悬停色、代码高亮亮暗配色、正文与标题字体以及卡片圆角/阴影。
- **正文美化与动效**：支持正文标题图标、两端对齐、头像悬停效果、分割线图标及可选背景/点击特效（默认关闭，尊重系统的 `prefers-reduced-motion` 设置）。

## 首页与顶图

- **首页布局**：提供多种文章列表与网格/瀑布流卡片布局，支持控制摘要生成方式与摘要长度。
- **顶图控制**：支持全局开关顶图、自定义默认顶图，文章/自定义页优先使用原生封面，也可在单篇元数据中单独覆盖是否显示顶图。
- **本地字幕**：首页支持配置固定副标题或打字机轮播文案。

## 侧边栏

- 支持切换左右位置、默认折叠、移动端显示开关以及右下角隐藏侧栏按钮。
- 内置卡片（作者信息、公告、最新文章、分类、标签云、归档、网站信息）与自定义侧栏卡片均可独立开关和排序。
- 可按页面类型（归档、分类、标签、单篇文章）控制侧边栏显示。

## 图片与懒加载

- 支持浏览器原生 `loading="lazy"`、可选渐进模糊过渡，以及图库/正文图片灯箱（基于 Viewer.js，支持缩放、旋转、键盘导航与无障碍焦点恢复）。
- 封面图片支持配置默认封面与多张随机候选封面列表。
