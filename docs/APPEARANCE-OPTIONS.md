# 侧栏、图片和外观配置

本批依据固定 Butterfly 5.7.0 的 `_config.yml`、`scripts/helpers/page.js` 和作者卡片/自定义 widget 布局适配 Halo。主题设置新增「外观」「动画特效」，原侧栏、文章封面和顶图配置继续使用原分组。

## 侧栏

作者卡片新增纯文本描述覆盖；留空使用作者简介或站点副标题。按钮增加启停和 CSS 图标类；文字/HTML 和链接仍读取原 `aside.button`，不改变旧配置。作者按钮和右下角隐藏侧栏按钮仍分别设置。

自定义卡片支持顶部/底部、位置内顺序、标题、图标类、CSS 类、ID 和 HTML。HTML 与原公告一样只供可信作者配置，原样渲染；标题和属性由模板转义。全局侧栏关闭或对应页面侧栏隐藏时不会输出卡片；简洁目录模式继续仅保留目录。无脚本时仍有卡片内容，位置内顺序采用配置列表顺序。

侧栏标签可以开启彩色显示、按公开文章数改变字号（12–21px），配置亮暗颜色对。颜色按排序和数量限制后的列表循环分配；空项/非法 CSS 颜色忽略；没有有效自定义色时采用主题已有的亮暗配色。关闭彩色选项继续使用原侧栏文字颜色。标签页提供独立自定义色及标签云展示方式；分类页可选可访问的层级列表，默认保留原统计图。

## 图片

「文章封面 → 默认封面候选列表」接受 `{url: 图片地址或 #/rgb/hsl 颜色}` 条目。空条目被过滤；候选存在时优先于原单张默认封面。文章原生封面始终优先。候选按文章 ID 的稳定索引选择，跨首页、侧栏、归档、上下篇及相关文章保持一致；不使用每次刷新重新随机的服务。候选清空后恢复原单张默认封面，再按旧图片加载设置回退。

这是对上游生成期随机封面列表的 Halo 适配，未声明其随机算法完全相同。无脚本时图片候选仍在服务端选择；颜色封面保留结构和文章链接，着色由脚本安全应用。该列表不改变顶图的原生封面优先级。

「图片 → 友链失败图片」与普通图片失败图分开。留空使用原图片加载设置的失败图；只尝试一次，重复地址或失败图也坏时隐藏图片，名称和链接保留。所有共享图片不再把用户 URL 拼接进内联错误处理器。无脚本时无法执行坏图回退，仍有替代文本和友链入口。

## 外观

- 字体：全局/代码字号、正文/代码字体族、站点标题字体族及可选样式表 URL。空值保持原字体；样式表仅允许 HTTPS 或同源 URL，显式填写才请求，失败仍回退系统字体。
- 配色：总开关控制主色、分页、悬停、选中文字、正文链接、元信息、分割线、行内代码、目录、引用、滚动条和亮暗浏览器主题色。空值保持原色。字号、字体、颜色和位置用 CSSOM 属性校验，拒绝 CSS/HTML 注入字符串。
- 正文：两端对齐、标题图标美化（仅文章或站点正文）、分割线图标/位置。图标使用 Font Awesome 私用区 Unicode，例如 `\f0c1`；无效值回退。已有标题锚点和目录行为保留。
- 头像旋转默认保留原效果，可以关闭；页面入场动画默认关闭。减少动态效果偏好优先于动画开关。

配色由作者选择，自定义颜色仍需检查亮暗可读性；现有默认可访问配色未替换。主题内联配置在首次绘制前设置字体和配色；禁用 JavaScript 时使用原主题样式。

## 动画特效

输入粒子、静态彩带、飘动彩带、连线背景、点击烟花、爱心和文字均默认关闭；对应功能开启才请求独立 `effects.min.js`。这些是主题自维护的行为适配，不引入上游第三方特效 SDK，不据相似效果声明第三方实现全等。

手机需要逐项开启；系统要求减少动态效果时全部停用。后台标签页停止绘制，页面离开时清理，浏览器返回时重新初始化。Canvas 的设备像素比上限 2、连线点上限 150、输入/烟花粒子上限 160、点击文字上限 20；输入粒子只响应文本/搜索框和 textarea，不读取或保存输入内容，不响应密码框。装饰层不拦截点击，链接、按钮和表单上的点击不会触发点击效果。

## 升级与回退

原作者按钮、单张封面、图片加载、主题字体选项和侧栏设置键继续保留。新字段缺失时使用旧行为；新卡片与候选列表默认空，彩色侧栏和特效默认关，分类/标签默认保留统计图。回退旧包会忽略新增字段；请保留升级前包和设置。新字段在迁移工具的目标默认值中自动补齐，不自动改写文章封面或用户资料。

限定真实 Halo 检查：安装候选包后运行

```sh
LAB_RUNTIME=/绝对路径/合成实验室 HALO_PORT=18143 HEXO_PORT=14143 \
  python3 scripts/appearance/validate.py
```

脚本只认领匹配端口及 ownership 的运行实例，使用独立无头 agent-browser。需要锁定 PluginLinks 2.3.0 和合成坏图友链以验证友链场景；其余内容采用仓库固定夹具。开始保存原设置及文章封面，结束恢复；报告与截图位于实验室上级 `validation/`，私有原始配置不会提交。
