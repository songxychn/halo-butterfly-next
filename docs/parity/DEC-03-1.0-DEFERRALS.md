# DEC-03 补充：1.0 资源优化与私有统计延期

日期：2026-10-15。依据：维护者在本任务明确确认“评论、KaTeX 资源懒加载的延期决定”及“Umami 私有统计也移出 1.0，保留访问追踪就行”，并要求同步提案、合同、待办，先解决页面加载失败和性能问题。本记录直接依据维护者授权，不代表已创建新的公开 issue。

## 范围与兼容边界

- 评论严格资源懒加载延期到 1.0 之后，版本未定。1.0 不要求首屏零评论 JS/CSS 下载；保留官方 CommentWidget 的资源注入、现有延迟组件挂载与数据请求、锚点立即加载、失败重试、草稿与生命周期验收。
- KaTeX 按页面公式有无加载插件资源延期到 1.0 之后，版本未定。1.0 不要求无公式页面零 KaTeX CSS/JS 下载；保留官方插件、公式阅读/复制/滚动、MathML、全局与逐篇显示控制、避免重复渲染、失败回退和插件组合验收。显示开关不宣称控制插件全站资源。
- Umami 私有统计后端延期到 1.0 之后，版本及承载方式未定。保留访问追踪；1.0 不要求建设凭据代理、私有报表读取和真实私有统计账户对账。已有可选公开只读统计接口不删除，其配置、安全和失败回退继续验收；不把私有凭据下发浏览器。
- 继续兼容 Halo 与官方已发布插件，不依赖定制插件、私有协议、删除或劫持官方注入，不为实现上述延期功能提高主题最低 Halo 版本。已有 PWA 延期与原生图片决定继续有效。所有延期均不等于已实现或验收通过。

## 新推进顺序

1. **P0 页面加载可靠性**：保留首页、文章、单页、归档、标签五类历史失败；从实际候选的浏览器请求和服务端日志定位图片、主题脚本、官方评论资源停滞，修复后复验。重跑通过或放宽超时不能替代原因和证据。
2. **P1 性能与原生图片**：处理首屏字体、阻塞 CSS/脚本及近屏图片开销；核对初始 HTML 与正文加载路径、首屏例外、响应式图片和 blur。保持实际性能预算，不因资源优化延期而降低预算。
3. **P2 已实现组合与映射**：继续 PJAX/评论/公式/瞬间/友链/国际化组合、正文与平台长尾映射。RSS/站点地图已实现，转 PLG-07 剩余验收，不重新列为首要开发。
4. **最终完整验收**：固定候选完成合同要求的双站、插件、性能、设备、辅助技术、安装升级回退、独立审查、CI 和发行门禁。
