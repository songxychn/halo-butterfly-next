# DEC-03 补充：PWA 延期、平台接入顺序与原生图片懒加载

日期：2026-10-15。依据：维护者本次明确确认“PWA 收益不大，1.0 可以先不做”“按这个优先级推进，图片接受原生懒加载”，并要求先同步提案及合同，再实施 RSS／站点地图并验收已有功能。公开登记：[#415](https://github.com/songxychn/halo-butterfly-next/issues/415)。本记录补充 [DEC-03 资源供应裁定](DEC-03-RESOURCES-DECISION.md)，取代其中仍将 PWA／离线列为 1.0 待定必需范围的表述；既有资源供应、评论、公式和通用正文裁定继续有效。

## 决定与实施顺序

1. RSS／站点地图继续属于 1.0，优先使用官方 Feed／Sitemap 插件提供数据与路由，主题接入发现链接、订阅入口及插件未安装/停用回退。锁定实际支持插件版本、端点与包哈希，执行合同 PLG-07；初始安装了插件不代表验收完成。
2. 评论／KaTeX 资源按需排第二，先处理评论，再处理公式。脚本下载、组件挂载、数据请求分别记录；未取得插件能力不能用主题开关声称全站注入已取消。原有首屏评论资源与无公式页按需要求保留。
3. 图片接受标准 `loading="lazy"`，目标为减少首屏图片开销、保持正文可读。不要求进入视口前严格零请求，也不再要求为此强制开发改写任意作者 `src/srcset` 的内容处理插件。保留作者 `src/srcset/picture`、显式 eager、首屏关键图片及无脚本可读；核对初始 HTML 与正文处理路径、范围/启停、实际加载、响应式图片、失败回退和 PJAX。浏览器可提前加载邻近图片；解析后补属性不能被记录为初始请求已经延迟的证据。已有占位/模糊等声明选项继续单独验收，不因接受原生方案自动取消。
4. Umami 私有统计代理排最后，仍需明确后端承载、API 版本、时间范围与 URL 归一化，保管私有凭据并完成真实账户对账。

PWA／离线延期到 1.0 之后，后续版本与是否实施待评估；不自动排入 1.1。本次不选择或部署 PWA 插件，不要求安装、离线缓存、worker 更新/卸载作为 1.0 成功条件。RSS／站点地图不依赖 PWA，不能随之延期。

已有实现继续验收；已知页面失败、性能预算和核心交互问题优先于新增 Umami 代理。第三方 PJAX 生命周期、国际化和其他平台映射长尾仍须处理。跨仓库修改、生产操作与正式发行并未因本决定自动授权，必要审批集中留到最后。

## 矩阵与分母

保留全部 897 个 ID 和上游来源。仅以下 8 个 PWA 项由 `gap` 转为 `blocked`，登记 `blocker.phase=post-1.0` 与本决定，不计入 1.0 工程分母，不标为已验收或不适用：

- `config:pwa.enable`
- `config:pwa.manifest`
- `config:pwa.apple_touch_icon`
- `config:pwa.favicon_32_32`
- `config:pwa.favicon_16_16`
- `config:pwa.mask_icon`
- `template:includes/head/pwa`
- `interaction:pwa`

既有 12 条系列活数据延期仍为 `phase=1.1`，184 条不适用不变。因此当前 1.0 适用分母由 701 调整为 **693**；20 条延期（12 条 1.1 + 8 条版本未定）与 184 条不适用分别单列。图片相关断言改按原生方案，原状态保持；仍为 `gap` 的两条旧处理 hook 需完成实际路径映射与验收后再更新。本次新增 `verified` 为 **0**，5 条既有页面失败保留。

RSS／站点地图没有独立的既有上游矩阵 ID，以新合同场景 **PLG-07** 和清单 P01 独立追踪；不复用 PWA ID，也不因其不在 897 条上游 ID 内而从完成条件遗漏。完整工程终点仍同时要求适用矩阵和合同场景通过。
