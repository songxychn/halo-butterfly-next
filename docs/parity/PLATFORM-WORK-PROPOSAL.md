# 1.0 平台工作提案

2026-10-15。当前范围以维护者确认的 [1.0 延期决定](DEC-03-1.0-DEFERRALS.md)、[DEC-03 平台补充](DEC-03-PLATFORM-DECISION.md)和[验收合同](../RELEASE-ACCEPTANCE.md)为准。评论/KaTeX 严格资源懒加载、Umami 私有统计和 PWA 均移出 1.0，后续版本未定；现有评论、公式与 Umami 访问追踪保留并继续兼容 Halo 和官方插件。

兼容边界：主题最低 Halo 版本保持 `>=2.20.2`。允许调整主题自身配置、模板和内部接口，不改变对 Halo 与官方插件的兼容要求；插件按各自官方版本要求使用，不依赖定制插件或私有协议。

## 1.0 之后，版本未定

| 需求 | 延期部分 | 1.0 保留能力 |
| --- | --- | --- |
| 评论资源懒加载 | 首屏零评论 CSS/JS 下载；不改造上游或要求定制插件。 | 官方评论、延迟挂载与数据请求、锚点、重试、草稿及生命周期。 |
| KaTeX 资源按需 | 无公式页零插件 CSS/JS 下载。 | 官方插件、公式显示/复制/滚动、MathML、逐篇控制、无重复渲染与失败回退。 |
| Umami 私有统计 | 私有凭据后端、认证报表读取、缓存/限流与私有统计账户对账；承载未定。 | Umami 访问追踪；已有可选公开只读接口的配置、安全及失败回退。 |
| PWA / 离线 | 安装、离线缓存、更新及卸载；是否实施待评估。 | RSS/站点地图独立保留。 |
