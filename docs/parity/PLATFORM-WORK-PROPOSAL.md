# 剩余平台需求实施提案（待维护者决定）

2026-10-14。本轮先完成主题仓库内已确认的开发与验收，以下方案供最后一次集中决定；尚未改变 1.0 范围，也没有部署生产、修改其他仓库或启用新的服务。通用 Markdown / HTML 决定继续有效。

| 需求 | 建议承载与主题工作 | 实施前需要确定 | 完成条件 |
| --- | --- | --- | --- |
| P01 / RSS、站点地图 | 使用 Halo 官方 [Feed](https://github.com/halo-dev/plugin-feed) 与 [Sitemap](https://github.com/halo-dev/plugin-sitemap) 插件提供数据和路由；主题负责发现链接/订阅入口及有无插件回退。 | 确认平台替代合同、锁定支持版本与主题入口。已有本地初始插件不等于已按本合同验收。 | 固定夹具检查公开文章、更新、排除私密/草稿、canonical 与插件停用；不得将 RSS/Sitemap 误并入离线缓存。 |
| P01 / PWA、离线 | 由服务端插件承担站点根作用域的 worker、manifest 与缓存边界；主题负责安装/更新提示及在线导航体验。 | 选择复用/扩展插件或独立维护配套插件。[已有社区插件](https://github.com/chengzhongxue/plugin-pwa)仅作为调研候选，README 自述基础功能，尚无本项目的离线/权限验收依据。 | 安装图标、公开页面离线、版本更新/恢复/卸载；后台、账户、API、私密内容不可被公开缓存；与其他主题/已有 worker 共存、失败回退。 |
| P02 / Umami 私有统计 | 服务端插件/受控只读代理保管凭据，公开端点只输出经过限制的 site_uv/site_pv/page_pv。主题继续使用现有公开读取接口。 | 选择承载仓库和部署位置、锁定 Umami API 版本及统计权限；凭据不写主题设置或公开 HTML。 | 无凭据泄漏、缓存/限流、站点绑定、请求失败回退；真实测试账户对账。两个 token 矩阵项仍属同一后端需求。 |
| P03 / 评论与 KaTeX 资源按需 | 插件提供取消全站/head 注入或按需模块入口；主题调用已有评论懒挂载与公式显示适配。 | 授权对应插件仓库工作或确认既有插件支持范围；不能用主题开关谎称插件已停止下载。 | 无评论首屏/无公式页的网络记录，启停/动态挂载/PJAX/失败重试和辅助 MathML 保留。 |
| D03 / 任意作者图片延迟处理 | 在 Halo 内容处理层解析 HTML，保留作者语义后处理 img/picture/srcset；主题继续消费标准 HTML 与显式延迟属性。 | 确定插件/API 承载、与 Halo 缩略图及其他内容处理器顺序。 | 浏览器预扫描前的真实网络断言、首屏例外、srcset/picture、失败恢复、无脚本可读；不得以脚本加载后删 src 冒充完成。 |

主题可以自主补接口、文档及回归；这些跨仓库/平台职责决定没有被本轮自动批准。真实 Safari/手机、屏幕阅读器、外部账户与最终发行仍按 [1.0 合同](../RELEASE-ACCEPTANCE.md)单独验收。网页调研仅确定候选职责，不等于候选插件已兼容或其最新发行已验证。
