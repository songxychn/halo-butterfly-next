# 1.0 平台工作提案

2026-10-15。当前范围以维护者确认的 [1.0 延期决定](DEC-03-1.0-DEFERRALS.md)、[DEC-03 平台补充](DEC-03-PLATFORM-DECISION.md)和[验收合同](../RELEASE-ACCEPTANCE.md)为准。评论/KaTeX 严格资源懒加载、Umami 私有统计和 PWA 均移出 1.0，后续版本未定；现有评论、公式与 Umami 访问追踪保留并继续兼容 Halo 和官方插件。

兼容边界：主题最低 Halo 版本保持 `>=2.20.2`。允许调整主题自身配置、模板和内部接口，不改变对 Halo 与官方插件的兼容要求；插件按各自官方版本要求使用，不依赖定制插件或私有协议。

## 当前实施顺序

| 优先级 / 需求 | 主题工作与完成条件 | 边界 |
| --- | --- | --- |
| P0 / 页面加载可靠性 | 对首页、文章、单页、归档、标签既有失败追踪实际浏览器请求与服务端日志，定位图片、主题 JS、官方评论资源停滞，修复后在对应场景复验。 | 历史失败保持候选归属；不以加超时或一次重跑通过代替问题定位。 |
| P1 / 性能与原生图片 | 优化字体、阻塞 CSS/脚本和图片首屏开销，验证实际性能预算。图片接受 loading="lazy"，核对初始 HTML/正文路径、启停与范围、src/srcset/picture、显式 eager、首屏关键图片、blur、失败及无脚本/PJAX。 | 不要求进入视口前严格零请求；不能以解析后补属性证明初始请求已延迟。严格插件资源优化延期不降低总体性能门禁。 |
| P2 / 已实现组合与平台映射 | 完成 PJAX、评论/公式、瞬间、友链、国际化和正文/平台长尾映射；RSS/站点地图按 PLG-07 做剩余验收。 | RSS/站点地图已接入官方 Feed/Sitemap，保留插件启停、数据隐私和 URL 一致性要求，不重新开发。未知 SDK 保持可靠完整导航。 |
| 最终 / 完整候选验收 | 固定候选完成双站、推荐插件组合、性能、真实 Safari/手机、键盘/屏幕阅读器、外部账户、安装升级回退、独立审查与 CI。 | 限定检查不自动提升 verified；正式发行和生产部署保留各自授权门禁。 |

## 1.0 之后，版本未定

| 需求 | 延期部分 | 1.0 保留能力 |
| --- | --- | --- |
| 评论资源懒加载 | 首屏零评论 CSS/JS 下载；不改造上游或要求定制插件。 | 官方评论、延迟挂载与数据请求、锚点、重试、草稿及生命周期。 |
| KaTeX 资源按需 | 无公式页零插件 CSS/JS 下载。 | 官方插件、公式显示/复制/滚动、MathML、逐篇控制、无重复渲染与失败回退。 |
| Umami 私有统计 | 私有凭据后端、认证报表读取、缓存/限流与私有统计账户对账；承载未定。 | Umami 访问追踪；已有可选公开只读接口的配置、安全及失败回退。 |
| PWA / 离线 | 安装、离线缓存、更新及卸载；是否实施待评估。 | RSS/站点地图独立保留。 |

仅 2 条纯 Umami token 矩阵项新增 blocked / post-1.0；评论和公式混合条目保留，只延期资源子要求。矩阵分母为 691，详情见[延期决定](DEC-03-1.0-DEFERRALS.md)。

实施证据：[RSS 接入说明](../RSS-SITEMAP.md)、[平台验收](../validation/2026-10-15/platform-acceptance.md)、[已有实现独立验收](../validation/2026-10-15/existing-feature-acceptance.md)、[官方插件资源边界](PLUGIN-RESOURCE-FOLLOWUP.md)。这些记录保留其原候选和限定范围，不代表本轮已重新执行。
