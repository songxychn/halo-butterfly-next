# 1.0 平台工作提案

2026-10-15。当前范围以维护者确认的 [1.0 延期决定](DEC-03-1.0-DEFERRALS.md)、[DEC-03 平台补充](DEC-03-PLATFORM-DECISION.md)和[验收合同](../RELEASE-ACCEPTANCE.md)为准。评论/KaTeX 严格资源懒加载、Umami 私有统计和 PWA 均移出 1.0，后续版本未定；现有评论、公式与 Umami 访问追踪保留并继续兼容 Halo 和官方插件。

兼容边界：主题最低 Halo 版本保持 `>=2.20.2`。允许调整主题自身配置、模板和内部接口，不改变对 Halo 与官方插件的兼容要求；插件按各自官方版本要求使用，不依赖定制插件或私有协议。

## 当前实施顺序

2026-10-24 最新结果见 [Halo 2.27.1 固定候选验收](../validation/2026-10-24/halo-2271-acceptance.md)：候选 `28d6656` / ZIP `4b13dd85…`，官方插件手机/桌面亮暗 **12/12 例、192/192 检查点**通过；正式性能 **160/160 有效、16/16 绝对及配对预算通过**。#338 已用官方正式包完成协议和历史矩阵复验并关闭；不再等待上游发布。新结果不改判历史失败，不代表评论提交、公式作者、真机或完整 1.0 合同已通过。

本轮固定主题候选，使用官方包补组合、性能及故障控制；随后按 [剩余清单](DEVELOPMENT-BACKLOG.md#已确认推进顺序) 补评论/Moment 实际交互、公式 WebKit 作者路径、导航/图片未覆盖范围、平台长尾和最终 RC。官方插件保留原生导航回退；不安装定制插件、不采用连接绕行、不提高最低 Halo 版本。

历史 2026-10-16/17 等待上游和部分通过的记录见原验收索引；本轮正式结果不追认历史根因或把旧失败改判。

## 1.0 之后，版本未定

| 需求 | 延期部分 | 1.0 保留能力 |
| --- | --- | --- |
| 评论资源懒加载 | 首屏零评论 CSS/JS 下载；不改造上游或要求定制插件。 | 官方评论、延迟挂载与数据请求、锚点、重试、草稿及生命周期。 |
| KaTeX 资源按需 | 无公式页零插件 CSS/JS 下载。 | 官方插件、公式显示/复制/滚动、MathML、逐篇控制、无重复渲染与失败回退。 |
| Umami 私有统计 | 私有凭据后端、认证报表读取、缓存/限流与私有统计账户对账；承载未定。 | Umami 访问追踪；已有可选公开只读接口的配置、安全及失败回退。 |
| PWA / 离线 | 安装、离线缓存、更新及卸载；是否实施待评估。 | RSS/站点地图独立保留。 |

仅 2 条纯 Umami token 矩阵项新增 blocked / post-1.0；评论和公式混合条目保留，只延期资源子要求。矩阵分母为 691，详情见[延期决定](DEC-03-1.0-DEFERRALS.md)。
