# 剩余平台需求实施提案（维护者已确认范围与顺序）

2026-10-15。维护者通过 [#415](https://github.com/songxychn/halo-butterfly-next/issues/415) 确认 PWA／离线延期到 1.0 之后，图片接受原生懒加载，并按下表顺序推进。决定与矩阵处理见 [DEC-03 平台补充](DEC-03-PLATFORM-DECISION.md)，1.0 成功条件见[验收合同](../RELEASE-ACCEPTANCE.md)。本记录批准本仓库内的实现、验证与独立审查；不代表生产部署、其他仓库修改或正式发行已获批准。

兼容边界：稳定版前可调整本主题自身的旧配置与内部接口，Halo／官方插件兼容要求继续有效。主题最低版本为 `>=2.20.2`，使用官方插件接口，不将插件功能增强作为本主题的使用前提。详见合同 v1.8。

| 优先级 / 需求 | 承载与主题工作 | 实施约束 | 完成条件 |
| --- | --- | --- | --- |
| 1 / RSS、站点地图 | Halo 官方 [Feed](https://github.com/halo-dev/plugin-feed) 与 [Sitemap](https://github.com/halo-dev/plugin-sitemap) 插件提供数据和路由；主题负责发现链接、订阅入口及插件未安装/停用回退。 | 接受平台替代；实施时锁定实际支持版本和路由，已有本地插件不等于通过验收。 | 固定夹具检查公开文章、更新、排除私密/草稿、canonical、插件启停与恢复；发现链接不重复，不暴露无效入口。按合同 PLG-07 验证，不并入离线缓存。 |
| 2 / 评论与 KaTeX 资源按需 | 兼容官方已发布插件接口，主题负责评论延迟挂载与公式阅读适配；官方插件的全站资源注入仍是能力边界。 | 不提交本次上游功能改造，不要求定制插件或私有协议；不能用主题开关谎称插件已停止下载。严格按需目标仍未满足。 | 分开记录脚本下载、组件挂载和数据请求；保留首屏评论资源与无公式页资源要求，验证启停、动态挂载、PJAX、失败重试和辅助 MathML。 |
| 3 / 图片原生懒加载 | 接受标准 `loading="lazy"`，保留作者 `src/srcset/picture`、显式 eager、首屏关键图片和无脚本阅读；核对主题可控输出与正文处理路径。 | 目标是降低首屏开销和保持正文可读；不要求进入视口前严格零请求，不再强制建设改写 `src/srcset` 的平台插件。 | 初始 HTML/实际加载、site/post 范围、启停、响应式图片、首屏例外、失败回退、无脚本与 PJAX 验收；不能把解析后补属性当成初始请求已延迟的证据。既有占位/模糊等选项仍单独验收。 |
| 4 / Umami 私有统计 | 主题保留现有可选公开读取接口；私有凭据须由服务端保管，后端承载待重新讨论。 | 不向现有 Umami 插件上游提交本次功能扩展，不擅自改建独立服务；承载、API 版本、统计口径仍需明确，不把凭据写入主题或公开 HTML。 | 无凭据泄漏、缓存/限流、站点绑定、请求失败回退及真实测试账户对账；两个 token 矩阵项仍属同一后端需求。 |
| 1.0 之后 / PWA、离线 | 从 1.0 必需范围移出，保留需求与上游来源。 | 后续版本与是否实施均待评估，不自动排入 1.1，不选择或部署 PWA 插件。 | 8 条矩阵项以 `blocked`、`blocker.phase=post-1.0` 单列；不计入 1.0 分母，不记为已验收或不适用。重启工作前再明确安装、缓存、更新、权限和卸载边界。 |

已有实现继续并行验收：已知页面失败、性能预算和核心交互问题优先于新增 Umami 代理；第三方 PJAX 生命周期、国际化与平台长尾映射不会因本排序被取消。真实 Safari/手机、屏幕阅读器、外部账户与最终发行仍按合同单独记录。任何限定检查通过都不自动提升 `verified`。

实施与证据：RSS／站点地图接入见[说明](../RSS-SITEMAP.md)，本轮可携带结果、失败和候选摘要见[验收记录](../validation/2026-10-15/platform-acceptance.md)；已有实现的独立批次见[独立验收](../validation/2026-10-15/existing-feature-acceptance.md)。评论／KaTeX 插件现有能力、Halo 版本限制和后续修改范围见[资源按需调查](PLUGIN-RESOURCE-FOLLOWUP.md)。这些记录是进展证据，不改变上表完成条件。
