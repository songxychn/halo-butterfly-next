# DEC-10：1.0 发布前收敛主题范围

2026-10-28，维护者明确授权在正式发布前大幅删减不应由主题承担的浏览器运行机制和外部服务。此决定优先于早期逐项复刻 Butterfly 的计划；移除项不是延期承诺，也不要求逐家服务重新验收。

## 删除

- PJAX 页面替换、预取、脚本白名单、手动浏览历史/滚动恢复以及为它们增加的插件和 SDK 适配。链接使用浏览器整页导航，Halo 负责自身访问追踪。
- 分析服务（百度、Google Analytics/GTM、Cloudflare、Clarity、Umami）、聊天服务（Chatra、Crisp、Tidio、Knocket）、AdSense 与主题广告槽。
- 不蒜子、全站逐篇抓取字数、Share.js/AddToAny 与对应打包资源和许可证副本。
- 一言、今日诗词、自定义字幕 API；保留本地字幕和打字效果。
- 上述功能专用的运行、测试及验收协调脚本。

## 保留

Butterfly 的视觉、布局、文章与单页、导航和分页、阅读增强、图片和代码、深色模式、本地字幕、按需正文渲染。搜索、评论、图库、瞬间、友链等继续通过 Halo 官方能力接入。分享只提供系统分享和复制链接，阅读量使用 Halo 原生数据。

保留普通页面内交互与小型资源清理工具，不引入新的路由框架。保留包内资源回退、URL 校验和作者主动设置的资源地址。这里的外部服务删减不意味着禁止文章外链、远程图片、自定义字体或站长主动配置 CDN。站点需要分析等服务时自行通过平台或现有注入能力管理，主题不再代管 SDK 生命周期。

## 升级行为

旧字段不会再驱动已删除的实现。离线迁移报告以 `removed-feature` 标出删除项，且 `needsReview=true`；不把服务凭据抄入新配置。Share.js/AddToAny 转为 `native` 并报告体验变化。原不蒜子提供方的两个 PV 开关关闭，避免误把 Halo 文章阅读量当作原服务统计；确认口径后可重新开启。`busuanzi.site_pv/page_pv` 暂保留存储键以兼容已有 Halo 原生开关，后台名称为「Halo 阅读量」。注入区中的手写脚本不自动删除，升级者需自行检查。

## 验证与发布

`bun run verify` 检查当前源码、配置、包和许可证。还需对删减后包在官方 Halo 上检查安装/升级、原生导航与历史返回、文章/单页、分享及官方插件。旧 269 文件候选及历史 PJAX/SDK 报告仅作旧版本记录，不能证明新包通过。

历史记录不重写；已移除脚本可从本次变更前提交 `313b2af0e6725f3dd87dd8b0a66431ea59835058` 找回。矩阵保留上游条目，将删除项标为有明确决定的 `not-applicable`。1.0 只要求明确范围内的发布门禁，不为消除矩阵所有差异而补功能。
