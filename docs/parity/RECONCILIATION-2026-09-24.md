## 保留的真实缺口

- 15 条正文标签已有样式准备，但主要规则位于当前标准正文缺少的 `.container` 祖先下，尚缺实际 DOM 接入、相应交互、参数域和离线转换证据，继续保持 `gap`。不能把样式模块 PR 等同标签能力完成。
- 菜单和字幕继续 `in-progress`：两级菜单/焦点管理与字幕已有实现，但上游菜单元数据、多层语义、字幕默认值/来源/完整参数尚未闭环。
- 原 Fancyapps/medium-zoom 资源条目保留 `gap` 并说明当前使用 Viewer.js。灯箱已实现部分用户能力，不代表每个上游提供方及选项都已实现，也不自动获得“不适用”裁定。
- 搜索关闭焦点的 alpha 例外保留，完整 1.0 门禁不豁免。历史 Linux 107/120、原主题对照中的双方资源无响应均未改写为成功。
- 实际 Safari、Android/iPhone 真机、屏幕阅读器、完整性能和真实外部提供方联调没有因本次文档对账获得通过结论。

## 功能矩阵之外的成果

这些工作有价值，但不能冒充某个用户功能的完整验收：

- PR #339 增加 Linux 浏览器验收，#334/#326 增加诊断；#341 修正主动刷新取消的归因，#342 补足关闭上下文前未完成资源的检测。工具修复不会自动改变旧产品运行结果。
- PR #320/#323/#336/#340 准备 alpha 计划、反馈模板及最终候选记录；#325/#328/#335 处理当前源码/发行包资源和许可。候选源码与 ZIP 的许可结论不覆盖整个私有 Git 历史。
- 全新安装、alpha.2 升级/回退与数据保留已有局部验收。原主题 2.0.5/2.0.7 配置迁移、Next 版本升级回退、Hexo 标签离线转换是三件独立事项；不能用其中一个替代其余 MIG/LIFE/EXT 合同。
- 现有性能诊断属于 `9593d49` 的单次模拟样本；不移记到最终 `776958ad`，不视为完整 PERF-01/02/03 达标。

## 后续推进顺序

1. 优先补有明确实际缺口的用户能力：正文标签 DOM/交互、完整配置映射和插件页剩余行为，按具体条目拆分，不按 PR 数估进度。
2. 对已有实现的条目执行固定 Hexo 5.7.0 双站对照与条目专属断言，把局部结果逐步补成合同证据。
3. 独立处理搜索焦点、资源加载、真机/实际 Safari、屏幕阅读器与性能门禁；公开 alpha 的例外不扩展到 1.0。
4. 最终 RC 绑定确切提交、包、运行/非作者审查/CI 与下载安装验证；验收完成后再更新 `verified`。
