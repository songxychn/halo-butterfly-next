# 搜索关闭焦点：公开 alpha 决策材料

当前复核（2026-10-08）：官方已发布 [SearchWidget 1.8.0](https://github.com/halo-dev/plugin-search-widget/releases/tag/v1.8.0)，由插件内部保存并恢复焦点，不要求主题接入新 API。Halo 2.26.1 满足其 >=2.26.0 要求。本仓库保留 >=1.7.1 入口兼容，当前验收固定 1.8.0；三引擎焦点专项 96/96 通过。精确身份、原始失败、集成结果及独立审查见 [1.8.0 验收记录](validation/2026-10-08/search-widget-1.8.md)。下文保留 2026-09-21 的历史决策，不代表当前上游状态；已发布 alpha.3 及演示站的插件未在本轮升级。

核查日期：2026-09-21。结论：**缺陷仍在，当前没有可直接升级的官方修复，也没有已公开的关闭事件供主题稳健接入。** 本文记录诊断、用户的公开 alpha 范围裁定及修复方案，不是缺陷修复或最终候选发布签署。

当前主题通过官方示例的 `SearchWidget.open()` 打开组件。主题只监听 Escape 不足以涵盖遮罩关闭；推断 body 的 overflow 变化容易把其他浮层当成搜索；监听插件私有 DOM、轮询内部 open 状态或覆写组件方法又引入未承诺的插件耦合。因此本轮不在主题中加入这些变通实现，不改变固定插件版本。

## 验收缺口与本轮改动

原 `scripts/search-comment/check.mjs` 已覆盖四组合的 Escape 焦点断言，但遮罩路径只检查弹窗关闭，随后直接重新打开搜索。现在补上独立的 `search-<width>-<mode>-backdrop-focus-return` 断言；其失败与 Escape 失败一样保留在报告，并使总流程返回非零。搜索查询/导航通过可以与焦点失败同时记录，不能据前者判定整体验收通过。

本轮没有运行或改变真实 Halo lab，因此**不把新增的四项遮罩断言声明为已复现或已通过**。源码显示两种关闭共用同一方法，预期仍失败；最终结论必须由冻结候选包的实际运行记录确定。现有 Escape 失败证据也不是未来候选包的验收结果。无服务 `pnpm verify` 不执行此真实插件流程。

## 对公开 alpha 的影响

按当前关闭焦点恢复要求，这是**搜索键盘可访问性及 1.0 验收的 blocker**。2026-09-21，用户明确允许公开 alpha 披露搜索关闭后焦点不恢复的已知限制后放行，并要求继续保留 1.0 失败门禁。因此它不再单独阻断公开 alpha；前提是在公开材料中明确披露，最终候选仍绑定实际失败证据。此裁定不将真实检查结果改为通过，不修改矩阵状态，也不等于其他 alpha 门禁已通过或已公开发布。

当前采用已获用户批准的“公开 alpha 明示接受限制”路径，继续准备其他候选材料，同时保留本项未通过。修复后的退出条件为：固定正式插件版本与候选包后，Escape/遮罩全部焦点场景实际通过并独立审查。以下保留其他修复路线供后续实施，未授权自建或修改上游插件：

| 路径 | 具体工作与代价 | 解除条件 |
| --- | --- | --- |
| 官方插件修复（优先） | 插件在打开时保存实际触发元素，关闭且 DOM 更新后恢复；处理入口被移除/隐藏、重复开关和结果导航。不依赖主题知道插件内部结构；时间取决于上游，当前没有可用发行版 | 官方发行版及固定 JAR 哈希到位，四组合 × Escape/遮罩、重复开关、结果导航回归；另外记录真实 Safari/真机未覆盖范围 |
| 官方关闭事件 | 上游承诺关闭事件与触发时序，主题记录触发入口并在关闭事件后恢复，避免与插件未来自带恢复重复竞争。需要插件与主题共同维护版本边界 | 已发布并有文档的 API，加主题回归、禁用/未安装/低版本行为验证 |
| 公开 alpha 明示接受限制（2026-09-21 用户已批准） | 仅测试站 alpha 接受搜索关闭丢焦点；发布说明、支持范围和测试反馈模板直述影响。临时处理是重新用 Tab 导航定位搜索入口，关闭后不能预期从原入口继续。不能宣称键盘无障碍或完整搜索验收通过 | 候选冻结时补充 SHA/包哈希、固定插件版本、缺陷证据与独立审查；自动检查仍失败，发布决策单独记录已批准例外；正式无障碍/1.0 门禁不豁免 |
| 本期不提供搜索 | 显式缩减 alpha 范围，隐藏搜索入口并说明原因；会损失核心功能，不能将停用后的“没有失败”算作搜索通过 | 用户批准范围变化，再验证入口/插件开关及发布说明；完整搜索合同保留未完成 |

维护独立插件分支或自建搜索前端会增加构建、授权归属、依赖升级及完整可访问性维护成本，属于另一个开发范围，不是本缺陷的小型主题修复。

下一次复核应重新查询官方 latest 与固定源码，再用最终候选包运行完整真实流程。原始失败报告、插件版本与独立审查结论必须保留，不修改矩阵为 `verified`。
