# 首次正式上架范围与验收项

2026-10-07，依据首次拒审意见和维护者授权准备。**此文固定本轮验收目标，不声明功能已正式验收通过。** 进度见[整改清单](APP-STORE-READINESS.md)。正式版本号在候选准备完成后确定，主题 ID 保持 `halo-butterfly-next`；不覆盖已发布 alpha.3，也不改变[完整 1.0 合同](RELEASE-ACCEPTANCE.md)。

## 功能范围

| 分类 | 本轮首发目标 | 必查场景 |
| --- | --- | --- |
| 内容页面 | 首页与分页、文章、单页、分类/标签列表及归档、文章归档、作者归档、404 | 有内容/空集合、长标题、缺封面/作者、长文、表格、代码、图片；分页首尾及无结果 |
| 导航与阅读 | 桌面/移动菜单、侧栏、目录、返回顶部、阅读配置、亮暗模式 | 多层菜单、键盘与焦点、移动目录开关、章节链接、模式保存、顶图开/关及明亮图片上的文字可读性 |
| 代码与图片 | 默认 One Light/One Dark 和 hopscotch 高亮、代码复制与折叠、图片灯箱 | 长行横向滚动、折叠后展开、复制内容、键盘入口、灯箱关闭焦点恢复；hopscotch 无在线字体请求 |
| 安装与配置 | ZIP 安装、启用、设置保存、alpha.3 升级、主题切换与回退 | 干净实例、旧配置缺新字段、自定义值保留、重启后生效、内容不丢失、备份及故障恢复 |
| 搜索与评论 | 可选集成准备；拟验证 SearchWidget 1.7.1 / CommentWidget 3.3.2，最终按实测版本固定 | 缺失/停用/低版本不显示入口；搜索成功/空态/Escape/遮罩关闭及焦点；评论权限、亮暗样式与提交；#313 尚未通过 |

其他继承代码配色、友链/图库/瞬间、公共插件布局、统计、外部字幕、打赏和相关文章按实现与证据逐项补验，不在正式市场说明中提前承诺。当前入口和配置未因此移除；最终候选如仍暴露这些能力，应验证正常使用及失败回退，或在冻结前明确调整交付范围，不能只改宣传文字隐藏实际问题。

不宣传全面对齐 Butterfly 5.7.0、全部插件生态兼容或任意自定义 CSS/第三方注入均可用。迁移若纳入首发说明，必须验证原主题配置转换、未支持字段报告、原主题共存及回退；不声称无损内容迁移。

## 平台及配置边界

- 当前源码及本轮 ZIP 只声明最低版本 `>=2.22.14`，不设上限；核心兼容检查覆盖官方 2.22.14、2.23.3、2.24.2、2.25.4、2.26.0、2.26.1；评论入口及公共插件页面布局需要 Halo ≥2.26.0，2.27.0-beta.1 单列为预发布实测，见[兼容验证记录](validation/2026-10-07/halo-lower-compatibility.md)。固定对照实验室仍使用 2.26.1。#338 原生加载问题仍阻塞市场验收；正式候选须复验实际支持环境，并把最低版本同步到市场字段。
- 默认亮色/暗色、桌面/手机宽度、顶图开/关均纳入核心检查。默认图片与白色压力夹具都检查文字可读性；历史接受明亮顶图限制不能算作正式通过。
- 核心页面在未安装可选插件时独立可用。推荐插件按名称、来源、版本、包 SHA-256 登记，逐项和声明支持的组合测试。
- 浏览器准备目标为 Chromium、Firefox、WebKit 桌面及手机视口；最终公开支持名单只写实际覆盖环境。手机端需实际 Android Chrome 和 iOS Safari 验证；缺设备时记录待验，不以视口或 User-Agent 模拟替代。
- 默认系统字体和主题自带资源不依赖 Google Fonts。用户配置的图片、API、CDN 或第三方服务单独列出触发条件、请求数据和不可用回退。

## 验收清单

以最终候选 ZIP 为对象。通过记录须包含环境、命令、实际结果和原始报告位置；失败保留，不靠删断言、延长超时或筛选重跑清除。

- [ ] 冻结正式候选版本、源码提交、Node/Bun 及锁文件、ZIP SHA-256、对应源码和 Halo/插件包身份。
- [ ] Node 24 / Bun 1.4.0 下冻结安装，`bun run verify`、`git diff --check` 通过；对应提交 CI、独立审查及重复/源码归档重建通过。
- [ ] 真实 Halo 全新安装并核对安装文件；启用、保存配置、重启、切换/切回和停用/卸载后内容保留通过。
- [ ] 已发布 alpha.3 → 候选 → alpha.3 → 候选，核对自定义配置、缺字段默认值和内容；首次无上一正式版的事实写入报告。
- [ ] 功能表中的页面、内容边界、默认/必要配置组合及键盘交互通过。
- [ ] 首发暴露能力的插件缺失、停用、启用和版本边界通过，未纳入的能力有明确处置。
- [ ] #338 在未经修改的官方正式 Halo 上重放固定复现和跨浏览器页面矩阵，通过后记录修复归属；#313 及默认明亮顶图可读性有有效处理和复验结果。
- [ ] 浏览器、实际手机、慢网、外部服务不可用、无 JavaScript 降级、长文和多图通过；性能按既有[测量方法](PERFORMANCE.md)保存重复结果，确定正式范围预算与结论。
- [ ] 安全、隐私内容、URL、错误配置、外部依赖、许可证和派生说明复核通过，支持链接有效。
- [ ] 正式版本、Halo 兼容范围及插件要求在市场字段、`theme.yaml`、README、安装文档、版本说明和验收记录一致。
- [ ] 最终包截图覆盖首页、列表、文章、亮暗及手机布局；记录各图路由、配置、时间、环境和包 SHA-256，上传市场截图栏。
- [ ] 维护者已审阅具体版本、安装包和材料，并授权重新提交。
