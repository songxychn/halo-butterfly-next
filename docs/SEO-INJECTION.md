# SEO、站点验证、订阅与代码注入

## SEO 与社交元信息

- 自动为首页、文章、单页及分页生成 `canonical` 链接与基础 Open Graph / Twitter Card 元标签。
- 支持开启 `WebSite`（首页）和 `BlogPosting`（文章页）JSON-LD 结构化数据，以及自定义网站别名。

## 站点验证与订阅入口

- 支持配置主流搜索引擎站点验证 `<meta>` 标签。
- 在安装 Halo 官方 RSS / Sitemap 插件后，可在主题设置中开启页头自动发现链接与订阅入口。

## 代码注入

- 提供 `head`（注入到 `</head>` 前）与 `bottom`（注入到 `</body>` 前）两个代码注入区，按配置顺序输出，兼容公共插件布局。
- 仅在信任的站点配置中使用自定义脚本；注入代码由站长自行负责安全性与兼容性。
