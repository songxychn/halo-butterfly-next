# 图库与瞬间服务端分页

[#32](https://github.com/songxychn/halo-butterfly-next/issues/32) 修复 `/photos` 和 `/moments` 只显示当前页内容、缺少显式上一页/下一页入口的问题。模板直接使用插件分页对象的 `prevUrl` / `nextUrl`，保留 Photos 的 `page`、`size`、`group` 和 Moments 的页路径、`tag`；不由主题 JavaScript 猜测翻页地址。

只有存在多页数据且当前页在有效范围内时输出带名称的导航区域。前后页链接按插件提供的状态显示，当前页使用可直接阅读的“第 2 页，共 5 页”文本。空列表和单页没有无效翻页入口。链接保持原生键盘 Enter、浏览器历史和另开标签语义，不依赖脚本事件接管。

样式仅作用于图库与瞬间的 `.plugin-pagination`，允许换行；触摸目标至少44×44px，键盘焦点使用2px外框与3px间距，明暗模式和悬停状态沿用已审查侧栏按钮的对比度配色。
