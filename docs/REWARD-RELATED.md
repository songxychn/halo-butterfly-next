# 打赏与相关文章

在 Halo 的主题设置 →「文章」中配置这两项。仅文章详情页显示，自定义页面不显示。

## 打赏

默认关闭。启用后，在「二维码」列表添加图片、点击链接及说明；图片为空的条目忽略。没有有效图片时不显示打赏按钮。按钮文字为空或仅为空格时显示「打赏」。

点击或触摸按钮打开，再次点击关闭；电脑也支持鼠标悬停预览。键盘可用 Enter / Space 切换、Tab 浏览关闭按钮及二维码链接、Escape 关闭。关闭按钮和 Escape 将焦点返回打赏按钮；点击外部或将焦点移出时关闭，保留新目标的焦点。

二维码链接为空时打开原图，填写链接时打开该地址，均保留浏览器的原生链接行为。图片加载失败仍显示可点击的提示。多张二维码在窄屏中滚动显示，弹层根据可用空间向上或向下展开。说明作为纯文本显示。

## 相关文章

默认开启，数量默认 6，日期默认显示发布时间。共同标签越多的文章越靠前；同等相关度随机展示，因此刷新后顺序可能变化。先排序再限制数量，排除当前文章和重复项。没有标签或没有候选时隐藏整个区域。

候选包含标签查询的后续分页，较早发布的高相关度文章也能参与排序。候选使用 Halo 的公开文章查询；草稿及私密文章在本次合成站点测试中均未出现在输出中。未选中的封面保留在惰性模板内，不触发图片请求。

选择「updated」显示更新时间，缺少更新时间时回退发布时间。数量非正数或无效时回退 6，正小数向下取整且至少为 1。空日期配置回退发布时间。

## 验证与边界

本次使用真实 Halo 2.26.1 和独立无头 Chromium / Firefox / WebKit，验证桌面与手机尺寸、亮暗模式，以及空列表、坏图片、多二维码、跨分页排序、日期和无标签等场景。详细记录见 [本地验收](validation/2026-10-06/reward-related.md)。测试中的图片为合成素材，没有发起支付请求。

这是作者本地验证；独立审查、远端 CI、Hexo 双站对照、真实 Safari 和实体手机验证尚未完成。矩阵维持 `implemented-unverified`。相关文章完整候选查询的超大站点性能尚未测量。

旧配置继续使用，不新增数据迁移。回退旧主题包即可恢复旧交互，已有二维码配置和文章数据保留。
