# 公开测试版计划

## 目标与发布定位

2026-09-21，维护者确认近期目标为公开测试版。先交付有明确支持范围、可安装和可回退的公开 alpha，让用户在测试站试用并反馈；完整 Butterfly 5.7.0 对齐及稳定 1.0 继续按 [1.0 工程验收合同](RELEASE-ACCEPTANCE.md)推进。

本文件是待执行的发布清单，不是验收通过记录。公开 alpha 不以全部 897 项矩阵验收为前置条件，也不改变矩阵状态、删减 1.0 范围或替代 1.0 的真机、性能等门禁。未完成能力必须在发行说明中可见。实际开放仓库、历史处理方式和发布渠道在候选材料齐备后交维护者确认。

候选使用新的预发行版本号，不覆盖已发布的 `v0.1.0-alpha.2`。冻结候选时同步主题元数据、包版本、安装文档和变更记录，再绑定精确提交、ZIP SHA-256 与证据索引。

## 首轮试用范围

| 范围 | 公开 alpha 的验收重点 |
| --- | --- |
| 平台 | 真实 Halo 2.26.1；其他版本只保留声明与未测说明，不承诺整个版本区间已验证 |
| 核心页面 | 首页及分页、文章、归档、分类、标签、自定义页和 404；正常、空数据、长内容及缺少作者/封面场景 |
| 核心操作 | 桌面/手机布局、菜单和键盘导航、深色模式、目录、代码折叠/展开/复制、图片查看和返回顶部；现有设置的默认值与关键开关 |
| 搜索评论 | 固定官方 SearchWidget 1.7.1、CommentWidget 3.3.2；查询/跳转/关闭、提交/回复/审核提示、权限开关、插件缺失/停用/恢复及可选评论计数 |
| 安装与恢复 | 全新安装、从已发布 alpha.2 升级、配置保留、回退到旧包；旧主题迁移继续明确支持字段和人工处理项 |
| 其他能力 | 友链/图库/瞬间、公共插件布局、正文扩展和其他高级设置按各自实际证据列为已测、实验性或未验证；不因模板存在就承诺支持 |

完成 PA-01 至 PA-06 后才能将候选标记为“待公开确认”。PA-07 完成后才能标记为“已公开测试”。没有明确结果的项目保持待完成；默认 CI 不运行真实 Halo、浏览器和插件联调，不能用绿灯替代这些证据。

## 推进顺序与反馈

1. 修复 #319，并处理搜索焦点问题的测试版结论。
2. 围绕核心用户路径集中回归、修复，完成安装升级与回退；避免用零散样式 PR 数量衡量发布进度。
3. 冻结新候选，完成独立审查、可重复构建及公开材料，提交最终公开方案。
4. 公开后收集 Halo/主题/插件版本、浏览器、复现步骤和脱敏日志；阻断阅读、导航、评论或升级回退的问题优先修复。不要求用户公开凭据、数据库或个人配置。

发布日期待首轮整体验收后估计；当前不承诺具体日期。公开测试的反馈用于后续候选和 1.0 验收，不自动将未验证的矩阵项提升为已验收。
