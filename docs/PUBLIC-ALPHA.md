# 公开测试版计划

## 目标与发布定位

2026-09-21，维护者确认近期目标为公开测试版。先交付有明确支持范围、可安装和可回退的公开 alpha，让用户在测试站试用并反馈；完整 Butterfly 5.7.0 对齐及稳定 1.0 继续按 [1.0 工程验收合同](RELEASE-ACCEPTANCE.md)推进。

本文件记录公开 alpha 的发布清单。当前 `v0.1.0-alpha.4` 已于 2026-10-09（Asia/Shanghai）公开发行并同步 demo，见[发行说明](RELEASE-alpha.4.md)及[发布完成记录](validation/2026-10-09/alpha4-publication.md)。本版 SearchWidget 固定 1.8.0，安装、alpha.3 升级回退、源码重建和资源许可检查经独立审查；限定 alpha 验收不提升完整矩阵状态。以下 alpha.3 清单保留历史归属。

`v0.1.0-alpha.3` 已于 2026-10-06（Asia/Shanghai）获维护者授权并公开发行，demo 已同步；下载、最终包身份与已知限制见[发行说明](RELEASE-alpha.3.md)，公开附件与部署核验见[发布完成记录](validation/2026-10-06/alpha3-publication.md)。[最终候选验收](validation/2026-10-06/alpha3-final-acceptance.md)保留当时尚待发布授权的状态，后续发布不改写原始测试结果。

公开 alpha 不以全部 897 项矩阵验收为前置条件，不改变矩阵状态、删减 1.0 范围或替代真机、完整无障碍及性能门禁。#313、#338 和默认明亮顶图对比度按已批准的 alpha 限制披露，手机性能未达目标及其他未验证范围继续保留。

2026-10-05 状态更正：[本仓库](https://github.com/songxychn/halo-butterfly-next)已公开，保留上游及后续维护的完整 Git 历史。维护者确认沿用现有公开仓库和历史，不采用另建无历史源码快照仓库的方案。仓库可见性与安装包发行状态分别记录。

候选使用新的预发行版本号，不覆盖已发布的 `v0.1.0-alpha.2`。冻结候选时同步主题元数据、包版本、安装文档和变更记录，再绑定精确提交、ZIP SHA-256 与证据索引。

历史功能集成提交为 `567b93f35f6d702a7398f4e9b7b684a8cb5f36bf`：封面元信息 #321、MIT 灯箱 #327、正文/默认代码主题 #329、空分类 #330、页脚 #331、导航/分页/列表链接 #332、标签云 #333 已合并。该记录说明源码修复状态，不代表随后版本/许可收口形成的最终 alpha.3 包已完成综合验证。

## 后续试用与反馈

1. 保留已接受的 #313、#338 和默认明亮顶图限制；自定义主题与未验证能力继续明确披露。
2. 收集 Halo/主题/插件版本、浏览器、复现步骤和脱敏日志；阻断阅读、导航、评论或升级回退的问题优先修复。不要求用户公开凭据、数据库或个人配置。
3. 后续候选重新绑定源码与 ZIP 身份，完成必要验证、独立审查、CI 及维护者发布授权；已公开 tag 和附件不覆盖。

alpha.4 已发布；后续版本日期尚未确定。公开测试的反馈用于后续候选和 1.0 验收，不自动将未验证的矩阵项提升为已验收。
