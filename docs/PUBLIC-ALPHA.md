# 公开测试版计划

## 目标与发布定位

2026-09-21，维护者确认近期目标为公开测试版。先交付有明确支持范围、可安装和可回退的公开 alpha，让用户在测试站试用并反馈；完整 Butterfly 5.7.0 对齐及稳定 1.0 继续按 [1.0 工程验收合同](RELEASE-ACCEPTANCE.md)推进。

本文件记录公开 alpha 的发布清单，不是最终候选验收通过记录。当前候选版本为 `0.1.0-alpha.3`，仍未公开；[发行说明](RELEASE-alpha.3.md)集中记录最终包身份、验证状态和已知限制，[安装与回退](INSTALL-UPGRADE.md)及[对应源码构建](SOURCE-BUILD.md)随候选准备。公开 alpha 不以全部 897 项矩阵验收为前置条件，也不改变矩阵状态、删减 1.0 范围或替代 1.0 的真机、性能等门禁。未完成能力必须在发行说明中可见。实际开放仓库、历史处理方式和发布渠道在候选材料齐备后交维护者确认。

候选使用新的预发行版本号，不覆盖已发布的 `v0.1.0-alpha.2`。冻结候选时同步主题元数据、包版本、安装文档和变更记录，再绑定精确提交、ZIP SHA-256 与证据索引。

本轮功能集成提交为 `567b93f35f6d702a7398f4e9b7b684a8cb5f36bf`：封面元信息 #321、MIT 灯箱 #327、正文/默认代码主题 #329、空分类 #330、页脚 #331、导航/分页/列表链接 #332、标签云 #333 已合并。该记录说明源码修复状态，不代表随后版本/许可收口形成的最终 alpha.3 包已完成综合验证。

## 推进顺序与反馈

1. 保留已合并的核心修复与搜索焦点公开 alpha 例外；关闭遮罩的明亮顶图导航/大标题、自定义主题和未验证能力继续明确披露。
2. 围绕核心用户路径集中回归、修复，完成安装升级与回退；避免用零散样式 PR 数量衡量发布进度。
3. 冻结新候选，完成独立审查、可重复构建及公开材料，提交最终公开方案。
4. 公开后收集 Halo/主题/插件版本、浏览器、复现步骤和脱敏日志；阻断阅读、导航、评论或升级回退的问题优先修复。不要求用户公开凭据、数据库或个人配置。

发布日期待首轮整体验收后估计；当前不承诺具体日期。公开测试的反馈用于后续候选和 1.0 验收，不自动将未验证的矩阵项提升为已验收。
