# 下载与预览说明

Halo Butterfly Next 0.1.0-alpha.4 是公开 alpha 测试版，面向测试站试用，不是稳定 1.0。安装附件及实际发布状态以 [alpha.4 发行页](https://github.com/songxychn/halo-butterfly-next/releases/tag/v0.1.0-alpha.4)为准。

下载 `halo-butterfly-next-0.1.0-alpha.4.zip`，按 `SHA256SUMS` 校验；发行页同时提供对应源码和验证记录。GitHub 自动生成的 Source code 压缩包不能直接安装为主题。

## 平台与验证范围

主题最低声明为 Halo ≥2.20.2，不设上限；声明不代表所有版本均已验证。demo 固定 Halo 2.26.1、SearchWidget 1.8.0，评论关闭。CommentWidget 3.3.2 与 SearchWidget 1.8.0 均要求 Halo ≥2.26.0。

## 当前已知限制

- SearchWidget 1.8.0 修复关闭焦点恢复；旧版 1.7.1 仍有已知限制。
- Halo 2.26.1 的原生静态资源请求可能挂起；原始失败保留，上游问题继续跟踪。
- 明亮顶图上的导航、站名和首页标题仍可能对比不足，建议选文字区域较暗的背景。
- 完整真机、Safari、屏幕阅读器、性能和 1.0 验收尚未完成。
- 插件生态和正文扩展按各自实际证据评估。

首次使用见[快速开始](../tutorials/getting-started.md)，已有站点先阅读[升级与回退](../tutorials/upgrade.md)。其他问题见[常见问题](faq.md)。
