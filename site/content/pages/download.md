# 下载与预览说明

**Halo Butterfly Next 0.1.0-alpha.3 正在准备，尚未公开发行。** 当前没有可向公众提供的正式 alpha.3 安装附件，因此本页暂不提供下载按钮。

这份文档内容围绕预览版本编写，可用于了解配置与功能范围。版本进入公开试用前，仍需要完成候选验证、对应源码与安装附件的核对。

## 已核对的平台范围

| 项目 | 验证基线 |
| --- | --- |
| Halo | 2.26.1 |
| 搜索插件 | SearchWidget 1.7.1 |
| 评论插件 | CommentWidget 3.3.2 |

主题元数据声明的兼容范围不代表其中每个版本都已测试。插件最低入口版本也不代表所有后续版本组合都已验证。

## 当前已知限制

- SearchWidget 1.7.1 关闭后不会自动把焦点返回搜索入口，需要继续使用 Tab 导航。
- 候选验证中仍有静态资源无响应和页面就绪超时的未解决记录。
- 完整真实设备、性能与 1.0 验收尚未完成，当前不是稳定 1.0。
- 友链、图库、瞬间等插件组合，以及正文扩展能力，需要按各自验证范围判断。

更具体的使用问题见[常见问题与限制](faq.md)。

## 公开版本就绪后会提供什么

本页将列出安装 ZIP、SHA-256、对应源码、适用平台与插件版本，以及发行说明。下载主题应使用构建好的安装包，不能直接上传 GitHub 自动生成的 Source code 压缩包。

GitHub 上已有公开的历史 alpha.1、alpha.2 预发布版本；它们不是本页介绍的 alpha.3，也不包含当前源码的全部改进。alpha.3 的正式下载入口仍待发行后提供。取得经维护者确认的预览包后，可以按[快速开始](../tutorials/getting-started.md)在测试站试用。

已有站点更新前请阅读[升级与回退](../tutorials/upgrade.md)，先保留备份和当前可用的主题包。
