# 下载与安装说明

请从 [GitHub Releases](https://github.com/songxychn/halo-butterfly-next/releases) 下载对应版本的 `halo-butterfly-next-<version>.zip` 主题安装包，并在 Halo 控制台的主题管理中上传安装。

> GitHub 自动生成的 Source code 压缩包用于源码构建，不能直接上传为主题安装包。

## 兼容环境

- **Halo**：最低支持 `>=2.20.2`，推荐最新稳定版。
- **搜索插件（可选）**：官方 SearchWidget `>=1.7.1`（推荐 `1.8.0`，需 Halo `>=2.26.0`）。
- **评论插件（可选）**：官方 CommentWidget `>=3.3.2`（需 Halo `>=2.26.0`）。

首次使用请阅读[快速开始](../tutorials/getting-started.md)，已有站点请先阅读[升级与回退](../tutorials/upgrade.md)，常见问题见[FAQ](faq.md)。
