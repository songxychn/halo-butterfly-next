# 使用文档

这组文档面向 Halo Butterfly Next 0.1.0-alpha.4 测试版，平台验证基线为 Halo 2.26.1。版本下载与验证范围请阅读[下载与预览说明](download.md)，了解安装包和已知限制。

## 第一次使用

从[第一次使用 Halo Butterfly Next](../tutorials/getting-started.md)开始。它说明如何识别主题安装包、安装并启用主题，以及首次访问时应检查什么。

如果你想先看实际效果，进入[功能演示导览](../demos/demo-guide.md)。

## 配置站点外观

| 你想完成的事情 | 对应教程 |
| --- | --- |
| 更换大图、简介与首页摘要 | [首页大图与项目入口](../tutorials/homepage.md) |
| 添加文档和页面链接 | [导航和页面入口](../tutorials/navigation.md) |
| 设置作者、公告与分类标签 | [侧栏与站点信息](../tutorials/sidebar.md) |

按这四篇的顺序配置，可以先得到一个完整可读的站点。首页沿用主题已有布局，文档和下载通过导航、置顶文章与侧栏进入。
