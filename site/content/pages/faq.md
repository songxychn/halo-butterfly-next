# 常见问题与限制

适用：Halo Butterfly Next 1.0.0 发行候选版内容。遇到问题时，先记录主题、Halo、插件和浏览器的实际版本。

## 应该从哪里下载主题

安装包只从对应版本的 GitHub Release 获取；预览中的版本不一定已经提供安装附件。实际状态以[下载与预览说明](download.md)为准。

## Source code 压缩包可以直接安装吗

不可以。Halo 需要构建好的主题 ZIP；源码压缩包用于开发或自行构建。获得正确安装包后，参照[快速开始](../tutorials/getting-started.md)。

## 为什么没有搜索或评论入口

先检查插件是否安装、启用并满足主题入口版本基线。搜索基线为 SearchWidget 1.7.1，评论为 CommentWidget 3.3.2。评论还受全局权限和具体文章、单页的允许评论设置控制。

当前本地预览停用搜索与评论插件，因此不显示搜索入口，演示内容也不开放评论提交。自己的站点需要启用时，按照[搜索与评论教程](../tutorials/search-comments.md)逐项检查。

## 关闭搜索后键盘焦点去了哪里

SearchWidget 1.7.1 有关闭后不返回搜索入口的已知限制。使用 Escape 或遮罩关闭后，需要重新用 Tab 导航。官方 1.8.0 已修复该问题，使用该版需要 Halo ≥2.26.0；当前本地预览未启用搜索插件。旧版失败记录保留。

## 页面一直等待或样式没有加载怎么办

打开浏览器网络面板，检查页面引用的脚本、样式和图片是否成功返回，以及响应是否真的是目标资源。记录失败地址、状态与错误文字，提供已脱敏的复现步骤。

先确认实际包版本，再区分浏览器缓存、网络路径和服务响应。#338 已在 Halo 2.27.1 官方包完成限定复验，历史失败记录保留。新问题仍应按实际请求排查，不应一律归结为缓存，也不要通过隐藏加载层声称修复。

## 首屏图片换了却没变化

检查全局背景图片与首页第一屏背景的配置关系，并确认新图片地址可访问。配置保存后刷新前台核对。详见[首页配置](../tutorials/homepage.md)。

## 能直接使用 Hexo 配置和标签吗

不能。Halo 的菜单、内容对象和主题配置不同；Hexo 的 `{% %}` 标签不会由本主题直接解析。配置迁移工具只处理已说明的旧 Halo Butterfly 配置，不转换 Hexo 文章。

## 安装 Next 会覆盖旧主题吗

Next 的主题 ID 为 `halo-butterfly-next`，与原 `theme-butterfly` 分开。请按[迁移教程](../tutorials/migration.md)处理配置，不要把两者的 ConfigMap 混用。

## 任意封面和颜色都能保证可读吗

不能。明亮顶图、自定义 CSS、高亮主题和注入代码都可能影响对比度与布局。保留遮罩，并检查真实页面的亮暗模式、手机宽度和键盘焦点。

## 图库、瞬间和友链都已验证了吗

已有固定版本组合的限定验收，但不等于任意插件版本均已验证。当前本地预览未启用这些插件，主要展示核心阅读与外观；运行实例与发行验收范围应分别核对。
