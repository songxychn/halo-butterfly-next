# 第一次使用 Halo Butterfly Next

适用：Halo Butterfly Next 0.1.0-alpha.3 预览内容，平台验证基线为 Halo 2.26.1。

Halo Butterfly Next 是用于 Halo 的博客主题。文章仍在 Halo 中管理，主题负责展示首页、正文、导航与侧栏。它不是可以单独启动的网站程序，也不解析 Hexo 的主题配置。

## 准备安装包

先阅读[下载与预览说明](../pages/download.md)。当前 alpha.3 尚未公开发行；拿不到正式安装附件时，不要把 GitHub 自动生成的 Source code 压缩包当作主题包上传。

拿到经维护者确认的主题包后，核对版本、来源和发行说明中的 SHA-256。安装附件的命名形式为 `halo-butterfly-next-0.1.0-alpha.3.zip`，相同文件名并不能证明内容相同。

已有站点请先备份数据库、附件与配置，保存当前主题包。第一次试用建议选择独立测试站；主题包本身不包含整站备份。

## 安装并启用

1. 登录 Halo 控制台，打开主题管理，上传准备好的主题 ZIP。
2. 确认主题 ID 为 `halo-butterfly-next`，再启用主题。
3. 先保留默认配置，打开前台首页，确认标题、导航和静态资源正常显示。
4. 发布一篇含标题、正文和封面的测试文章，检查首页卡片和文章页。

空站没有分类或标签内容时，相关列表可能为空。搜索和评论依赖对应插件，安装主题不会自动完成插件配置。

## 完成第一次配置

先设置 Halo 的站点名称，再配置主菜单。用自己的封面替换首页大图，把首页字幕设为一段介绍。然后填写侧栏的作者信息和公告。

- [首页大图与项目入口](homepage.md)：背景、简介、卡片与摘要。
- [导航和页面入口](navigation.md)：主菜单、文档总览与手机菜单。
- [侧栏与站点信息](sidebar.md)：作者按钮、公告和分类标签。

这些入口都使用主题已有能力。首页标题下不增加新的操作按钮。

## 检查读者实际看到的页面

在桌面和手机宽度下分别访问首页、文章、分类和归档，切换一次深浅色模式。检查正文目录、图片和代码块；安装插件后再检查搜索与评论。

如果页面一直等待或资源加载失败，先保留浏览器错误与版本信息，参照[常见问题](../pages/faq.md)排查。当前预览仍有资源加载和搜索焦点方面的已知限制，不能把一次首页打开成功当成完整兼容验证。

已经使用旧主题的用户，请先读[旧主题迁移](migration.md)；同 ID 的版本更新则使用[升级与回退](upgrade.md)。
