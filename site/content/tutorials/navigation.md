# 设置导航和页面入口

适用：Halo Butterfly Next 0.1.0-alpha.3 预览内容，菜单核对基线为 Halo 2.26.1。

主题读取 Halo 的主菜单。先创建并发布文章或自定义页面，再把它们的实际访问地址加入菜单，避免读者点击后到达草稿或不存在的页面。

## 建立清晰的顶层入口

建议依次安排首页、使用文档、功能演示、更新日志、预览说明与 GitHub。其中“使用文档”指向总览页，“功能演示”指向导览文章。

没有更新日志内容时，先不展示空的更新日志入口。本项目的 GitHub 菜单指向[现有公开仓库](https://github.com/songxychn/halo-butterfly-next)。配置自己的站点时，也应检查站外链接是否对普通访客可访问。

在 Halo 控制台建立菜单项后，将该菜单指定为主菜单。每次更改都回到前台核对文字、目标页面和打开方式。文章网址应从前台实际页面取得，不要凭文章标题推测。

## 直接链接与分组

没有子项的菜单项是直接链接。有子项的菜单项在本主题中负责展开分组，所以不要期待点击分组标题同时进入文档总览。

第一版文档站采用直接链接进入总览页。如果个人站需要分组，可以把“文档总览”作为分组中的第一个子项，再排列安装、配置等链接。

菜单项可以填写图标属性。使用当前主题包含的 Font Awesome Free 图标，避免复制旧站使用的 Pro 专用图标后出现空白。

## 手机菜单

移动菜单分组默认展开。“移动菜单默认折叠”属性只改变分组初始状态，不会隐藏菜单项。旧菜单如果没有这个属性，也按默认展开处理。

菜单名称太长时，先尝试更短的名称和更少的顶层项。主题会在顶栏容纳不下时改用菜单抽屉，但仍需检查手机上的换行和滚动。

## 检查键盘操作

使用 Tab 移动到菜单入口，按 Enter 或 Space 展开分组。Escape 应关闭已展开的分组或抽屉，并把焦点返回相应入口。逐项检查焦点是否可见、当前页面是否标记正确。

站外链接、锚点和特殊查询地址不一定会得到当前页面标记，这不代表链接失效。最终以点击或键盘进入的实际目标为准。
