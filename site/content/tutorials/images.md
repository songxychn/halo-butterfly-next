# 使用图片与灯箱

适用：Halo Butterfly Next 0.1.0-alpha.4 测试版内容，内置灯箱使用 Viewer.js 1.14.0。

先打开[图片演示](../demos/demo-images.md)，体验风景照片的缩放和多图切换。文章封面用于卡片或顶图；正文中的图片用于阅读与灯箱查看，两者应分别配置。

## 插入正文图片

将图片上传到自己的 Halo 附件存储，在正文插入实际可访问的地址。尽量使用合适尺寸的图片，避免为了一个小缩略图传输特别大的原文件。

在 Markdown 中，图片方括号里的文字是替代文本。例如：

```markdown
![蓝色山脊倒映在平静湖面上](实际图片地址)
```

替代文本描述图片承载的信息；图片下方的说明文字可以补充背景。不要只写“图片一”，也不要把整段正文塞进替代文本。

## 打开和关闭灯箱

主题会为符合条件的正文图片添加查看入口。点击图片，或用键盘聚焦后打开，可以缩放、切换图片，并使用旋转、翻转、重置等工具。

普通查看状态下，Escape 关闭灯箱。播放幻灯片时，第一次 Escape 先停止播放，再按一次关闭。关闭后，焦点应返回仍然存在且可见的图片入口。

主题有手机触摸交互实现，但不能把桌面浏览器模拟手机宽度等同于真实手机验收；正式使用时仍需在自己的设备上查看。

## 多图与链接

默认情况下，同页符合条件的图片进入同一集合。切换下一张时，应保持在当前页面的图片范围内。

链接到原图的图片可以打开灯箱；普通网页链接和下载链接保留原生导航。需要让图片作为导航入口时，要在实际页面确认链接目标没有被灯箱接管。

熟悉 HTML 的作者可以使用 `data-no-lightbox` 排除图片，或用 `data-lightbox-group` 显式分组。编辑器可能过滤这些属性，保存并发布后要检查最终效果，不能仅看编辑状态。

## 检查显示与来源

检查图片是否在亮暗模式下清晰、竖图是否溢出、加载失败时是否还能理解正文。不要依赖过期的临时外链。

本演示使用 Pexels 摄影图片，来源说明见[演示站配置](../pages/site-setup.md)。换成照片时，应同时记录来源和可用范围；模板中的示例图片不自动赋予其他素材使用许可。
