# 配置搜索与评论

适用：Halo Butterfly Next 0.1.0-alpha.3 预览内容。本文以 Halo 2.26.1、SearchWidget 1.7.1、CommentWidget 3.3.2 为已核对的组合，不表示所有更高版本都已验证。

搜索和评论由 Halo 插件提供。主题负责提供入口、页面挂载和样式，不替插件创建搜索数据或决定评论审核规则。

## 启用搜索

在 Halo 中安装并启用官方 SearchWidget，确认版本满足主题入口的最低基线 1.7.1。随后访问一篇已发布文章，使用文章中有辨识度的词进行搜索。

分别检查有结果、无结果、键盘打开和结果跳转。插件未安装、停用或低于基线时，搜索入口隐藏是主题的预期行为，不应通过额外 HTML 硬加入口。

SearchWidget 1.7.1 有已知限制：使用 Escape 或遮罩关闭后，焦点不会自动回到原搜索入口，键盘用户需要继续使用 Tab 导航。这项问题尚未修复。

## 启用评论

安装并启用官方 CommentWidget，主题入口最低基线为 3.3.2。检查 Halo 的全局评论设置，再检查具体文章或页面是否允许评论。

根据站点需求设置访客权限与审核策略。使用一条无敏感信息的测试评论验证提交、回复及审核后的展示；不要仅确认页面里出现了输入框。

插件升级、权限变更和主题切换后，重新访问页面并检查实际挂载。插件版本号满足最低值不代表所有使用场景已经通过兼容验证。

## 评论数量

文章元信息中的评论数由 `comments.count` 控制，首页等卡片上的评论数由 `comments.card_post_count` 控制，默认都关闭。

显示计数还需要插件满足基线、全局评论启用，以及该文章允许评论。计数来自 Halo 的文章统计，不应把暂未显示数字直接判断成评论数据丢失。

## 演示站如何处理

首版内容清单默认关闭文章和单页的评论提交，先让访客专注阅读与功能展示。本地样站已启用官方 SearchWidget 1.7.1，可以通过顶栏搜索本站文档。关闭后的焦点恢复限制仍然存在，不能据此声明完整键盘无障碍验收通过。

反馈前请准备主题、Halo、插件与浏览器版本，附复现步骤。日志与截图先移除 Cookie、Token 和个人信息。更多问题见[常见问题与限制](../pages/faq.md)。
