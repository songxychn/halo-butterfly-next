# 配置侧栏与站点信息

适用：Halo Butterfly Next 0.1.0-alpha.3 预览内容。

侧栏可以帮助读者认识站点，并从文章回到文档和分类列表。官网样站使用作者卡片、公告和内容分类，不需要新增专用文档卡片。

## 作者卡片与入口

在“基本设置”里填写作者用户名时，使用 Halo 用户的唯一标识，不是显示昵称。留空或用户不存在时，主题使用站点信息作为回退。

“侧边栏按钮”包含名称和链接。可将名称设为“使用文档”，链接填入[文档总览](../pages/docs.md)的实际网址。当前模板会在新标签页打开这个按钮链接，配置后请检查是否符合自己的使用习惯。

社交账号按需要填写。删除无关的默认示例链接，确认每个图标和账号地址都属于自己的站点。

## 公告展示版本信息

公告可以写明当前站点使用的主题版本、Halo 版本和预览状态，并链接到[下载说明](../pages/download.md)。不要把主题的兼容声明写成“所有这些版本都已测试”。

公告支持 HTML，但简单文字和普通链接通常就够用。样站不会在这里嵌入脚本或第三方统计服务。

## 显示范围与排序

| 配置 | 用途 |
| --- | --- |
| 全局侧栏开关 | 关闭后优先于各页面显示选项 |
| 侧栏位置 | 在主栏左侧或右侧显示 |
| 窄屏显示侧栏卡片 | 决定手机宽度下是否保留侧栏卡片 |
| 页面显示选项 | 分别控制归档、标签和分类页面的侧栏 |
| 卡片顺序 | 数值越小越靠前，相同值保持原始顺序 |

卡片排序作用于普通页面的完整侧栏。文章页有自己的目录与阅读布局，目录不参与这些卡片的统一重排。主题目前也不提供已实现的逐文章侧栏元数据开关。

## 分类标签与归档

分类数量默认 5，标签数量默认 25；设为 0 表示不限制数量。内容很多时先限制数量，避免侧栏比正文还长。标签可以按名称、文章数量或随机顺序排列，样站选择名称排序以便查找。

分类层级来自 Halo 的分类关系。没有 JavaScript 时仍提供受数量限制的基础链接，层级展开等增强效果需要脚本正常加载。

归档可按月或年分组。“最后更新时间”表示公开文章的最近发布或修改时间，不是主题升级时间。

设置后查看首页、文章、归档和手机页面。文章页只想保留目录时，阅读[文章与阅读体验](reading.md)中的简洁侧栏设置。
