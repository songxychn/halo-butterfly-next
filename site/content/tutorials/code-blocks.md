# 使用代码高亮与代码工具栏

适用：Halo Butterfly Next 0.1.0-alpha.4 测试版内容。可同时打开[代码演示](../demos/demo-code.md)查看效果。

主题可以为代码块增加语言标题、行号、复制和折叠等操作。最终效果同时取决于正文生成的代码结构和主题配置。

## 写入带语言的代码

使用 Markdown 编辑器时，在围栏后填写语言名称，例如 `javascript`、`json` 或 `bash`。下面是一段 JavaScript：

```javascript
const title = 'Halo Butterfly Next';
console.log(`欢迎阅读 ${title} 的使用文档`);
```

使用富文本编辑器时，选择代码块组件并设置语言。发布后再检查高亮；编辑器预览与前台主题并不一定采用同一套样式。未知语言可能仅显示普通代码文本。

## 调整工具栏

在主题的正文渲染设置中，先启用代码块，再按需要配置：

| 设置 | 对应字段 | 建议 |
| --- | --- | --- |
| 代码标题 | `render.enable_code_title` | 开启，便于辨认语言 |
| 行号 | `render.enable_code_line` | 教程引用行号时开启 |
| 复制 | `render.enable_code_copy` | 开启，并实际检查复制结果 |
| 默认折叠 | `render.enable_code_expander` | 从默认展开开始，长代码再选择折叠 |
| 自动换行 | `render.enable_code_word_wrap` | 按长行阅读习惯选择 |
| 全屏 | `render.enable_code_fullpage` | 有长代码时按需启用 |

默认折叠字段是枚举值，不要直接把它当作布尔字段写入配置。通过控制台选项配置更容易避免类型错误。

## 长行与长代码

关闭自动换行时，长行通常需要横向滚动；开启后更适合窄屏阅读，但行与行的视觉对应关系会变化。

代码高度限制与默认折叠是不同的功能。调整其中一项后，检查最后几行能否到达、复制内容是否完整、展开按钮是否仍可见。不要通过给正文整体增加横向滚动来掩盖单个代码块的问题。

## 配色与复制边界

默认浅色和深色代码主题分别为 One Light、One Dark。自选其他高亮主题后，请在两种模式下检查注释、字符串和选中状态。

复制可能受到浏览器权限或页面环境影响。实际点击一次，并把内容粘贴到临时编辑器里核对，不要仅凭成功提示判断。若文章单独关闭了复制相关元数据，即使全局开关开启，也应检查该文章的实际行为。

这些代码只用于说明排版。读者复制其他文章的命令前，仍应理解命令的目标和输入内容。
