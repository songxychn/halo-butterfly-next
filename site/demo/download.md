# 下载与预览说明

本站演示 **Halo Butterfly Next {{version}}**，使用与 GitHub Release 下载附件相同的主题安装包。

[前往 {{version}} 的发行页面]({{releaseUrl}})，下载 `halo-butterfly-next-{{version}}.zip`，并使用 `SHA256SUMS` 核对摘要。发行页同时提供对应源码与验证记录。GitHub 自动生成的 Source code 压缩包不能直接作为主题 ZIP 安装。

## 平台与验证范围

本站固定使用 Halo 2.26.1、SearchWidget 1.7.1，评论关闭。各版本支持范围、已知限制和发行性质以对应发行说明为准；alpha、beta、rc 均为预发行版本，不能视为稳定版。

SearchWidget 1.7.1 关闭后焦点恢复的已知限制仍需遵循版本发行说明。源码验证与手机宽度截图不代表所有真机、插件及性能场景已完成验收。

首次使用见[快速开始](../tutorials/getting-started.md)，已有站点请先阅读[升级与回退](../tutorials/upgrade.md)。
