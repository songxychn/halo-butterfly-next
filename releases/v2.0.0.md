# Halo Butterfly Next 2.0.0

这是 2.0 正式版，沿用 `2.0.0-alpha.1` 的主题源码和配置结构。

## 从 1.0.0 升级的主要变化

- 主题设置由 42 组整理为 12 组。离线迁移工具支持 Halo Butterfly Next 1.0.0、0.1.0-alpha.4，以及原版 Halo Butterfly 2.0.5 和 2.0.7 的配置。
- 前端改用原生 DOM 和 ES Module，移除了 jQuery 和 ClipboardJS。各页面共用核心样式和脚本，繁简转换等模块按需加载。
- 修复无痕模式下侧栏折叠、圆形和沙漏加载动画，以及 Halo 首次初始化时缺少嵌套默认值的问题。减少相关文章和归档的重复查询。

## 下载与升级

下载 `halo-butterfly-next-2.0.0.zip`，用 `SHA256SUMS` 核对后在 Halo 控制台上传。源码归档为 `halo-butterfly-next-2.0.0-source.tar.gz`。

从 1.0.0 升级前，请备份 Halo 数据、旧主题 ZIP 和导出的主题配置。用迁移工具转换配置，核对报告后再导入。需要回退时，重新上传旧版 ZIP 并恢复升级前的配置。[安装、升级与回退](https://github.com/songxychn/halo-butterfly-next/blob/v2.0.0/docs/INSTALL-UPGRADE.md) · [配置迁移指南](https://github.com/songxychn/halo-butterfly-next/blob/v2.0.0/docs/MIGRATION.md)

主题声明的最低版本为 Halo 2.20.2。2.0 的主题源码已在 Halo 2.26.1 上验证安装激活、默认设置、主要页面渲染和主题资源加载。[实机验证记录](https://github.com/songxychn/halo-butterfly-next/pull/443) · [Linux 浏览器回归](https://github.com/songxychn/halo-butterfly-next/actions/runs/45021648961)
