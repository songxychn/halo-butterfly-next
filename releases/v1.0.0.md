# Halo Butterfly Next 1.0.0

首个正式版本，聚焦 Butterfly 的布局、视觉和阅读体验，以及 Halo 原生文章、单页和官方插件入口。

## 下载与安装

下载本页附件 `halo-butterfly-next-1.0.0.zip`，在 Halo 控制台安装主题。`halo-butterfly-next-1.0.0-source.tar.gz` 是对应源码包；`SHA256SUMS` 和 `release-validation.json` 提供附件校验和、源码身份及验收记录。

最低 Halo 版本为 `>=2.20.2`；本次固定运行验收使用 Halo 2.27.1、CommentWidget 3.3.2 和 SearchWidget 1.8.0，不代表每个版本及插件组合均已实测。源码重建使用 Bun 1.4.0。

## 主要变化

- 保留 Butterfly 的布局与阅读体验、本地字幕、系统分享和复制链接；导航、浏览历史与访问追踪使用浏览器和 Halo 原生能力。
- 按 [DEC-10](https://github.com/songxychn/halo-butterfly-next/blob/v1.0.0/docs/parity/DEC-10-THEME-SCOPE.md) 收缩主题边界：移除 PJAX/预取、分析/聊天/广告 SDK、Share.js/AddToAny、不蒜子、浏览器全站字数/最新评论聚合、远程字幕与动态/友链 JSON API、自建评论挂载、单项 CDN 资源覆盖，以及无调用方的页面生命周期和外部脚本加载器。
- 正文图库使用普通 HTML 图片与 CSS 网格，复用正文灯箱；修复开启图注后图片和图注错位的问题。旧 JSON 图库需按[图库说明](https://github.com/songxychn/halo-butterfly-next/blob/v1.0.0/docs/ARTICLE-GALLERY.md)转换内容。
- 正式发布与 Demo 镜像推广分开执行，宿主机控制器归 infra-ops；本次发布不更新公网 Demo。

## 升级与回退

升级前备份安装包、主题配置和 Halo 数据，运行离线配置迁移并核对 `removed-feature` / `experience-changed` 报告。旧 `comments.lazyload`、`aside.card_newest_comments` 和 `CDN.option` 不再生效，资源仅支持统一 assets 地址。原不蒜子数据与 Halo 阅读量口径不同，迁移默认关闭旧提供方开关。注入区脚本需自行检查。

回退应同时恢复旧包及旧配置，详见[迁移说明](https://github.com/songxychn/halo-butterfly-next/blob/v1.0.0/docs/MIGRATION.md)与[安装/升级说明](https://github.com/songxychn/halo-butterfly-next/blob/v1.0.0/docs/INSTALL-UPGRADE.md)。

## 验证与已知边界

独立审查、701 项测试、真实 Halo 受影响路径验收、新安装、alpha.4 升级/迁移/回退、冷备恢复及干净源码归档重建均通过。受测 ZIP 与源码重建产物逐字节一致，见[最终验证记录](https://github.com/songxychn/halo-butterfly-next/blob/v1.0.0/docs/validation/2026-10-29/release-readiness.md)及[发布记录](https://github.com/songxychn/halo-butterfly-next/blob/v1.0.0/releases/v1.0.0.json)。

真实 Safari/手机、完整无障碍、所有编辑器/插件组合尚无完整覆盖。所测 WebKit 在刷新恢复评论图片草稿后存在上传失败限制，不外推所有 Safari。原生图片初始加载和编辑器增强属性保留也有边界。PWA、评论/公式严格零资源按需仍延期；不宣称完整 Butterfly 对齐。旧性能与双站对齐报告不自动适用于本版。
