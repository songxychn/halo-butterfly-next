# Halo Butterfly Next 1.0.0

发行说明草案：当前仅准备安装包与对应源码，尚未打 tag、公开发布或更新公网 demo；独立本地 demo 已供维护者预览。

## 交付范围

Butterfly 的 Halo 社区维护版。沿用主题 ID `halo-butterfly-next`，保留原有布局、阅读增强、正文通用 HTML 能力及官方插件入口；恢复 Butterfly 标题与首页副标题的一秒入场动画，以及页脚浅色文字、无下划线链接和无导航时的版权分行布局。

- 采用 Halo 原生访问控制；不兼容 Hexo 密码解密协议。
- 正文语言和界面语言分开，界面使用 Halo 原生语言方案。
- 提示块使用通用 HTML 的 info/success/warning/danger 语义，不承诺旧 Hexo 全部外观参数。
- 评论、搜索、公式及公共插件页面遵循官方接口和必要的完整导航回退，不要求定制插件。

## 安装与升级

建议 Halo 2.27.1；最低声明 `>=2.20.2`，评论入口及公共插件布局要求 Halo >=2.26.0，插件同时遵循各自官方版本要求。固定验收组合和证据见发行准备记录。

安装文件为 `halo-butterfly-next-1.0.0.zip`，发布获准后以同一发行页的 `SHA256SUMS` 核对。源码归档不能直接安装。同 ID 更新前备份数据库、附件、主题完整配置和旧安装包，先在测试站演练。回退使用保存的旧包及配置，主题回退不回退文章与评论。详见[安装、升级与回退](../docs/INSTALL-UPGRADE.md)。

从 alpha.4 升级时，先导出旧配置，使用已有离线迁移工具 `--from 0.1.0-alpha.4` 并检查报告；新运行时不再根据已删除或改名的旧字段选择行为。存储值保留不等于旧外观自动等价，回退须恢复旧配置。

## 已知限制

- 所测 Playwright WebKit 的评论图片草稿在刷新后恢复 File 并上传时失败；新选图片直接上传对照正常。不外推实际 Safari，也不承诺图片草稿刷新后可靠续传。
- 编辑器保存增强属性有差异，普通图片入口不保证初始懒加载属性；原生 blur 不生成低清图。
- 恢复动画后的候选没有新的性能预算通过结论；不以取消或缩短原有动画换取测试分数。
- 亮色顶图可能造成文字对比度不足，应选择合适的背景与配色。
- 不宣称任意插件/SDK、全部 Halo 版本或完整 Butterfly 5.7.0 等价。真实 Safari/手机、完整无障碍、真实外部账户与长尾组合未穷尽。
- PWA、Umami 私有统计、评论/公式严格零资源按需等按既有决定延期；现有访问追踪、评论与公式功能保留。

本轮只更新本地 demo 文案与页脚，移除演示站额外页脚导航；不部署或升级公网 demo。已公开 alpha.4 与旧 demo 的实际运行版本不因这份说明变为 1.0。
