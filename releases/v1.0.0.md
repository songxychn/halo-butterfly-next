# Halo Butterfly Next 1.0.0 候选

尚未正式发布。#434 候选的运行、安装回退、独立审查和源码重建记录保存在[收口记录](../docs/validation/2026-10-28/scope-release-closure.md)。本次后续收缩改变了源码；[v1.0.0.json](v1.0.0.json) 已标记原候选被替代，新包须重新汇总受影响验证和审查，不能继承原包摘要或放行决定。

本版聚焦 Butterfly 的布局、视觉和阅读体验，以及 Halo 原生文章、单页和官方插件入口。按 [DEC-10](../docs/parity/DEC-10-THEME-SCOPE.md)，删除 PJAX/预取、分析/聊天/广告 SDK、Share.js/AddToAny、不蒜子、浏览器全站字数/最新评论聚合、远程字幕与动态/友链 JSON API、自建评论挂载及单项 CDN 资源覆盖。保留本地字幕、系统分享与复制链接；导航、浏览历史和访问追踪使用浏览器与 Halo 原生能力。

升级前备份安装包、主题配置和 Halo 数据，运行离线配置迁移并核对 `removed-feature` / `experience-changed` 报告。旧 `comments.lazyload`、`aside.card_newest_comments` 和 `CDN.option` 不再生效，资源仅支持统一 assets 地址。原不蒜子数据与 Halo 阅读量口径不同，迁移默认关闭旧提供方开关。注入区脚本需自行检查。回退应同时恢复旧包及旧配置，详见 [迁移](../docs/MIGRATION.md) 与 [安装/升级](../docs/INSTALL-UPGRADE.md)。

已知边界：真实 Safari/手机、完整无障碍、所有编辑器/插件组合尚无完整覆盖；既有 WebKit 评论图片草稿恢复限制需继续披露。PWA、评论/公式严格零资源按需仍延期。旧性能与双站对齐报告不自动适用于新包。

正式发布须确认最终 PR 与合并后 CI，并取得维护者明确发布授权；发布后另行核验公开制品。公网 demo 尚未随本次变更更新。

本次进一步删除无调用方的页面生命周期和外部脚本加载器，正文图库改为普通 HTML 图片与 CSS 网格。旧 JSON 图库需要[内容迁移](../docs/ARTICLE-GALLERY.md)。正式发布与 Demo 镜像推广分开执行；宿主机控制器归 infra-ops。
