# Halo Butterfly Next 1.0.0

首个正式版本，聚焦 Butterfly 的布局、视觉和阅读体验，以及 Halo 原生文章、单页和官方插件入口。

## 下载与安装

下载本页附件 `halo-butterfly-next-1.0.0.zip`，在 Halo 控制台主题管理中上传安装。`halo-butterfly-next-1.0.0-source.tar.gz` 为对应源码包，`SHA256SUMS` 提供附件校验和。

最低 Halo 版本为 `>=2.20.2`；官方搜索插件（SearchWidget ≥1.7.1，推荐 1.8.0）与评论插件（CommentWidget ≥3.3.2）按需安装。

## 主要变化

- 完整提供 Butterfly 布局与阅读体验、本地字幕、系统分享与复制链接、亮暗模式、代码块高亮、目录、数学公式（KaTeX 插件适配）及正文图表/乐谱渲染。
- 聚焦主题本身职责：评论与搜索交给 Halo 官方插件，导航与访问统计使用浏览器和 Halo 原生能力。
- 正文图库采用普通 HTML 图片与 CSS 网格，复用 Viewer.js 灯箱，修复开启图注后图注错位的问题。

## 升级与回退

升级前建议备份旧主题包、主题配置与 Halo 数据，可运行 `bun run migrate` 迁移旧版配置。详见 [安装与升级指南](../docs/INSTALL-UPGRADE.md) 与 [配置迁移说明](../docs/MIGRATION.md)。
