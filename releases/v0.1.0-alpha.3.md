# Halo Butterfly Next 0.1.0-alpha.3

**技术验收通过，待维护者发布授权，尚未发布。** 维护者已决定保留默认样式，将明亮顶图的文字对比度问题列为本次 alpha 已接受限制。该项及 #338 均不再阻塞本次 alpha 发行，原始失败仍保留。独立审查已批准候选包的四项限定 alpha 技术门禁；技术批准不等于授权创建 tag/Release。Hexo Butterfly 主题在 Halo 的移植版本；对齐目标为 Butterfly 5.7.0，尚未完成全部功能对齐。

## 相对 alpha.2 的主要变化

- 增加文章与自定义页的目录设置、单篇覆盖、章节链接、滚动锚点、可选图片说明和工具栏排列；支持侧栏卡片顺序、数量和页面显示控制。
- 适配 Halo 多层菜单与手机分组；补充首页字幕来源和打字参数，远端失败时回退本地文案。修正首页顶图布局与默认样式。
- 使用 MIT Viewer.js 1.14.0 灯箱；改善文章元信息、默认代码高亮、标签云、页脚和评论计数的可读性及键盘操作。当前顶图样式已在后续对齐改动中调整，早期导航渐变遮罩的检查不能代替本包验证。
- 修复空分类图表、代码折叠按钮裁剪、移动布局与侧栏统计；页面脚本延后执行，Prism 按需增强，慢加载时保留原始代码阅读。
- 四种 Loading 在正文就绪后退出；可选评论数默认关闭，遵守全局、单篇权限及插件支持版本。
- 自维护浏览器代码迁移至 TypeScript，构建使用 Node.js 24 与 Bun 1.4.0；补齐第三方许可与来源说明，移除来源未核实的旧素材。
- 补齐继承 vanilla-lazyload 的 MIT 原文和 Andrea Verlicchi 署名，准确披露版本与模块包装差异。新包仅增加两份许可材料，原有运行文件字节不变。
- 新增 demo / 文档站、独立照片封面和安装指南。发布工作流校验主题 ZIP 与对应源码，发布成功后构建 Halo/H2 demo 镜像，hk 按版本更新；master 合并不触发线上更新。首次公开 Release 到 demo 的完整自动链路仍待实际发布验证。

## 兼容性与升级

实际验收基线为 **Halo 2.26.1、SearchWidget 1.7.1、CommentWidget 3.3.2**。元数据声明不等于所有版本组合都已验证。安装包名为 `halo-butterfly-next-0.1.0-alpha.3.zip`，不要把对应源码归档上传为主题。

升级前备份 Halo 数据及主题配置，在测试站演练回退。同 ID 更新保留配置；从其他主题迁移请按[迁移说明](../docs/MIGRATION.md)处理。回退 alpha.2 时仍需注意旧包关闭文章顶图后的 JS 缺陷。

## 已知限制

- **已接受的 Halo 上游限制：** Halo 2.26.1 的本地与 Linux 验收出现 CSS、JS 或图片请求挂起，可能影响页面加载。维护者已裁定 [#338](https://github.com/songxychn/halo-butterfly-next/issues/338) 不阻塞本次 alpha 发行；原始失败继续保留，未宣称已修复或已获 Halo 官方根因确认。范围与证据见[资源加载裁定](../docs/RESOURCE-LOADING-DECISION.md)。
- **已获公开 alpha 例外：** SearchWidget 1.7.1 关闭后焦点未返回搜索入口；键盘用户需重新 Tab 导航。实际测试仍记失败，见[裁定记录](../docs/SEARCH-FOCUS-DECISION.md)。该例外不涵盖资源超时。
- **已接受的 alpha 可读性限制：** 保留 Butterfly 默认样式。即使开启默认遮罩，浅色导航、站名和首页标题在明亮/白色顶图下仍可能对比不足；维护者已明确接受该限制，不阻塞本次 alpha。建议选择文字区域较暗的图片，并检查实际可读性。原始失败保留，不代表无障碍或 1.0 验收通过；此项与 Halo 资源挂起无关。
- 真实 Safari、手机、屏幕阅读器、完整性能与 1.0 功能矩阵没有全部通过。本包本轮每场景5次测量：模拟手机首页/长文 LCP 中位数约6.95/4.66秒，桌面约1.26/0.88秒；手机超过2.5秒目标，不承诺性能达标。没有同环境旧包基线，不声称无退化。
- 高级插件生态、正文扩展及第三方字幕服务按各自验证记录评估；模板存在不等于功能已验收。旧版本和完整 Git 历史的资源许可不能由本次安装包检查追溯保证。

反馈请附版本、复现步骤和脱敏截图/日志，不要提交密码、Token、Cookie、数据库或个人配置。
