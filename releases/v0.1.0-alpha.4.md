# Halo Butterfly Next 0.1.0-alpha.4

公开 alpha 测试版，面向测试站试用。尚未完成 Butterfly 5.7.0 全面对齐或稳定 1.0 验收。

[在线 demo 与文档](https://butterfly.baizhukui.com/) · [安装、升级与回退](../docs/INSTALL-UPGRADE.md)

## 相对 alpha.3 的变化

- 完成打赏弹层的开关、焦点恢复、多二维码滚动与手机布局；相关文章按共享标签权重排序并处理标签分页。
- 改善手机首页和文章的首屏图片加载。已有固定环境采样显示改善，手机 LCP 仍未达到 2.5 秒目标。
- 移除代码块在线字体，改用本地系统等宽字体。
- 主题最低 Halo 声明调整为 ≥2.20.2，不设上限。已测具体版本与失败边界见[兼容记录](../docs/validation/2026-10-08/halo-earlier-compatibility.md)。
- SearchWidget 集成验收与 demo 升至官方 1.8.0，修复搜索关闭后的入口焦点恢复；主题搜索入口最低仍为 1.7.1。1.8.0 和 CommentWidget 3.3.2 都要求 Halo ≥2.26.0。
- 当前源码构建统一使用 Bun 1.4.0，保留独立 TypeScript 类型检查；历史版本沿用其原工具链。
- demo 的下载、搜索说明与版本标识同步更新。

## 安装与验证

安装 `halo-butterfly-next-0.1.0-alpha.4.zip`，使用 `SHA256SUMS` 核对。对应源码 tar.gz 与 GitHub 自动生成源码归档不能直接作为主题安装包。升级前备份数据和主题配置，在测试站演练回退。

真实 Halo 基线为 2.26.1，搜索 1.8.0；评论 3.3.2 的既有集成记录单列。新包验收身份及范围以随版 `release-validation.json` 和[alpha.4 验收记录](../docs/validation/2026-10-08/alpha4-acceptance.json)为准；历史报告保持原源码、包摘要和失败，不转记为本版全面验收。

## 已知限制

- #338：Halo 2.26.1 原生资源请求仍可能挂起。近期 Linux 三引擎矩阵 117/120 通过，3 项资源等待失败保留各自运行身份；没有把失败改绿或宣称全部同因已证实。
- 默认明亮顶图可能导致导航、站名与首页标题对比不足。保留默认样式，建议选择文字区域较暗的图片并检查可读性。
- SearchWidget 1.7.1 的焦点恢复缺陷仍存在；建议升级 1.8.0。新版限定回归通过不等于完整无障碍验收通过。
- 手机性能未满足目标；真实 Safari、真机触摸/软键盘、屏幕阅读器、全部插件组合和完整 1.0 门禁仍未完成。
- demo 内容以仓库为来源，后台修改不会跨版本保留。公开 alpha 发行不代表 Halo 应用市场已通过审核。

反馈请附主题、Halo、插件、浏览器版本和复现步骤，移除密码、Token、Cookie、数据库及个人信息。
