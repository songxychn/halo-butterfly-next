# Halo Butterfly Next 2.0.0-alpha.1

2.0 的首个预发行版，适合在测试站点试用。1.0.0 仍是稳定版。

## 主要变化

- 主题设置从 42 组整理为 12 组，配置迁移工具支持从 Halo Butterfly Next 1.0.0、0.1.0-alpha.4 及原版 Halo Butterfly 2.0.5、2.0.7 转换。
- 移除 jQuery 和 ClipboardJS，改用原生 DOM 与 ES Module 多入口。页面共享核心 CSS 和 JS，繁简转换等模块按需加载。
- 修复无痕模式下侧栏折叠、圆形与沙漏 Loading 的标记，以及 Halo 首次初始化设置时的嵌套默认值。减少相关文章和归档的重复查询。

## 下载与升级

下载附件 `halo-butterfly-next-2.0.0-alpha.1.zip`，用 `SHA256SUMS` 核对后，在 Halo 控制台的主题管理中上传。对应源码见 `halo-butterfly-next-2.0.0-alpha.1-source.tar.gz`。

从 1.0.0 升级前，请备份 Halo 数据、主题 ZIP 和导出的主题配置。迁移工具会生成新配置与字段报告，请核对后再导入。回退时重新上传旧版 ZIP，并恢复升级前的配置。[安装与回退指南](https://github.com/songxychn/halo-butterfly-next/blob/v2.0.0-alpha.1/docs/INSTALL-UPGRADE.md) · [配置迁移指南](https://github.com/songxychn/halo-butterfly-next/blob/v2.0.0-alpha.1/docs/MIGRATION.md)

主题声明的最低版本为 Halo 2.20.2。合并前在 Halo 2.26.1 上检查了安装激活、默认设置、首页、文章、归档、分类、标签、独立页面及主题资源。[验证记录](https://github.com/songxychn/halo-butterfly-next/pull/443)
